## 三、多任务编排规则

### 3.1 并发执行原则

**唯一真实依赖**：第 9 章和第 10 章必须在第 1-8 章全部完成后才能写。

```
第 1~8 章 → 8 章全部并发（互相不依赖——每章讲的关系路径互为正交，先跑）
            │ (全部完成)
            ▼
第 9 章+第 10 章 → 并发（开场要巡礼全书因果网、结语要收束全书）
            │ (全部完成)
            ▼
        合并全书 + 自检
```

**为什么 1-8 章可以完全并发**：
- 每章讲的关系路径互为正交——理解"互动→粉丝关系"不需要先理解"消耗与缓冲"
- 每一章的 task 文件里有完整的因果方向、源材料索引、双维度要求、案例需求
- 不需要读其他章的 output——每章自己管自己的素材，查到分配表有空闲的就去占

### 3.2 素材分配：先到先得 + 双维度匹配

**一句话规则**：素材没有预先分配。谁先写完谁先占，晚到的人自己想别的例子或去 B 站搜新的。

#### 每章素材底线

| 要求 | 每章最低 |
|------|---------|
| 正面例子 | ≥ 2 个（展示因果方向成立的样子） |
| 反面例子 | ≥ 2 个（展示因果方向被忽视的后果） |
| 真实翻车片段 | ≥ 1 个 |
| DUAL-SCALE 真实案例 | ≥ 2 个，分布在至少 2 个体量档位 |

#### 例子必须匹配双维度

| 体量 | 推荐例子体量 |
|------|-------------|
| 小体量（<50人） | 小体量主播 |
| 中体量（50-500人） | 中体量主播 |
| 大体量（>500人） | 大体量主播 |

**时间维度匹配**：DUAL-SCALE 部分需要找跨时间尺度的例子——
- 单场因果：找一场直播内的互动片段
- 短期跨场：找连续几场的状态变化
- 中期跨场：找一个月维度下的趋势
- 长期积累：找数月积累带来的结构性变化

#### 先到先得操作流程

**每个 Task 启动时**：
1. 读 `素材分配表.md`，看哪些素材状态是 `待分配`
2. 根据你要写的关系路径和双维度要求，挑合适的例子
3. 挑中了哪个，**立即**用 `StrReplace` 把分配表里那条的状态改成你的章节号
4. 写章节时直接用

**素材不够**：搜 B 站——
```bash
python "d:/createProject/GrowthPlan3/复盘提升词2/写书任务/工具脚本/search_bilibili.py" "你自己定的搜索词" --count 5
```
注意：search_bilibili.py 的 `PROJECT_ROOT` 是 `Path(__file__).parent.parent`，
即 `写书任务/`。所以搜出来的素材会下载到老任务的 `B站素材库/`。
下载后，手动将 `.txt` 文件移到本目录的 `B站素材库/`，并在本目录的 `素材分配表.md` 中登记。

## 六、各章节定义与关系路径映射

### 第 1 章：互动是枢纽节点

**覆盖关系路径**：①→ 人设→互动（快变量）、①↺ 互动→人设（慢变量）

**核心因果**：人设决定了你怎么互动，互动反过来慢慢塑造人设。互动是六维度最核心的枢纽——五条关系路径经过它。

**写作要点**：
- BAD：读者以为"人设是我自己定的"，实际人设是被观众的互动记忆塑造的
- DUAL-SCALE 时间重点：①→ 是单场可见的快变量，①↺ 是跨场可见的慢变量——引导读者区分"快"和"慢"
- 中国文化映射：人靠衣装马靠鞍（前台）、日久见人心（互动→人设慢变量）

**源材料**：`源材料/各学科内容/12_印象管理_Goffman.txt`、`六道因果络_学科验证.md` 关系路径①

### 第 2 章：互动 → 粉丝关系

**覆盖关系路径**：② 互动→粉丝关系

**核心因果**：不是"互动好了粉丝关系就好"——是你怎么互动，决定了吸引谁来、谁来留下、留下的人变成什么角色。

**写作要点**：
- BAD：读者以为"粉丝多是因为我聊得好"，实际粉丝关系的类型是由互动方式筛选出来的
- DUAL-SCALE 时间：单场可见——今晚的互动方式今晚就能看到谁在回应
- 体量差异大：小体量是一对一，大体量是文化归属

**源材料**：`源材料/各学科内容/17_准社会交往_HortonWohl.txt`、`源材料/各学科内容/06_自我决定理论_DeciRyan.txt`

### 第 3 章：互动 ≈ 内容质量

**覆盖关系路径**：③ 互动≈内容质量（约等于——不恒等）

**核心因果**：在直播这个纯口语文化环境里，内容不是"你说得多好"——是"你说完之后弹幕跟上了没有"。但两者不完全恒等——脱钩本身就是重要信号。

**写作要点**：
- BAD：读者以为"我的内容很好只是互动差"，实际在口语传播中，没被弹幕接住的内容等于没发生
- SCALE 部分必须说明"约等于"的边界：什么时候成立、什么时候不成立

**源材料**：`源材料/分片分析/05_内容质量分析.txt`、`六道因果络_学科验证.md` 关系路径③

### 第 4 章：双路互惠

**覆盖关系路径**：④ 互动→营收（交易型互惠）、②' 粉丝关系→营收（关系型互惠）

**核心因果**：互动产生的价值分两路——情感部分去了粉丝关系，非情感部分去了营收。老粉刷礼物不是因为今晚互动好，是因为两年关系。

**写作要点**：
- BAD：读者以为"今晚礼物少是因为今晚互动差"——忽略了关系型互惠这个独立路径
- 关键区分：交易型互惠是单场结算，关系型互惠是跨场积累
- 中国文化映射：礼尚往来（交易型）、情义无价（关系型）

**源材料**：`源材料/各学科内容/03_社会交换理论_ThibautKelley.txt`、`源材料/各学科内容/04_消费心理学_行为经济学.txt`

### 第 5 章：消耗与缓冲

**覆盖关系路径**：⑤ 互动表现→状态（情绪劳动消耗）、⑤' 粉丝关系→状态（社会支持缓冲）、⑦ 内容质量→状态（认知负荷）

**核心因果**：三种力量在同时影响你的状态——互动时的人格偏差在消耗，内容层面的认知负荷在消耗，但好的粉丝关系在缓冲。同一池子，不同来源。

**写作要点**：
- BAD：读者以为"直播累是因为播太久"——忽略了表面表演的消耗远大于物理时长
- 关键区分：⑤ 是人格偏差消耗，⑦ 是认知负荷消耗——同一个资源池，不同消耗源
- 中国文化映射：强颜欢笑、掏空了、脑子转不动了

**源材料**：`源材料/各学科内容/07_情绪劳动理论_Hochschild.txt`、`源材料/各学科内容/08_压力应对模型_Lazarus.txt`

### 第 6 章：崩塌与维持

**覆盖关系路径**：⑥ 状态→人设（后台崩塌）、⑥' 营收⇄状态（双向反馈）、⑩ 人设→内容（叙事同一性约束）

**核心因果**：状态持续差不会自己好——它会直接摧毁你的人设。营收是你"做得好不好"的即时反馈，正循环和负循环都很快。同时，你的人设决定了你能说什么。

**写作要点**：
- BAD：读者以为"累了明天就好了"——连续三场状态差，你的人设在不知不觉中崩塌
- DUAL-SCALE 时间重点：⑥ 单场可检测（验证时序），但真正的崩塌需要跨场看
- 中国文化映射：兜不住了、藏不住了、人如其名
