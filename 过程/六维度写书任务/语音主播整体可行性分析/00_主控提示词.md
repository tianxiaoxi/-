# 六维度框架 · 语音主播大规模实战验证主控提示词

> **目标**：通过大规模实战检验，验证"六道因果络"分析框架在纯语音主播（无视觉层）群体的有效性和修正方向。
> **核心问题**：当主播没有任何视觉层时——没有虚拟形象、没有真人面孔——六维框架是否依然成立？哪些路径需要修正？
> **输入**：`../../六道因果络_学科验证_v2.md`（分析框架，通用）
> **分析工具**：`.cursor/skills/voice-streamer-six-dim-review`（语音主播六维分析 skill）
> **输出路径**：`复盘提升词2/六维度写书任务/语音主播整体可行性分析/`

---

## 总体流程

```
Phase 1: 全球语音主播筛选 → Phase 2: 并行分析 → Phase 3: 框架评估与统计汇总
```

## Phase 1：全球语音主播筛选与素材归档

### 1.1 筛选目标

覆盖全球各地区的**纯语音/音频直播主播**——即直播中**不使用任何视觉画面**（无摄像头、无虚拟形象、无屏幕共享作为主要内容），纯粹以声音进行直播的主播。

| 目标 | 说明 |
|------|------|
| 覆盖范围 | 喜马拉雅FM（中国）、荔枝FM（中国）、猫耳FM（中国）、B站音频直播（中国）、抖音语音直播（中国）、Discord语音频道（全球）、Twitch音频模式（全球）、Clubhouse/Twitter Spaces（全球）、Spoon Radio（韩国）、Radiotalk（日本）、ツイキャス音声配信（日本）等纯音频/语音直播平台 |
| 数量策略 | **不设上限**——搜到多少符合条件的就纳入多少。注意：语音主播的公开资料比真人主播少，信息不足的排除率会更高 |
| 筛选标准 | 仅排除"公开信息不足以支撑六维分析"的主播。语音主播的基本门槛：至少有粉丝数/听众数的公开数据 + 有近期动态或讨论 |

## Phase 2：并行六维分析

- 从业时长：{时长}
- 内容类型：{类型}
- 听众规模：{规模}

要求：
1. 严格按照 skill 中定义的工作流执行（搜索→六维评分→关系路径→心之壁→报告）
2. **搜索时必须覆盖主播所在平台的本地语言内容**
3. 语音主播的公开资料可能比真人主播少——信息不足的维度明确标注而非臆测
4. 分析完成后，将完整报告保存到 复盘提升词2/六维度写书任务/语音主播整体可行性分析/reports/{主播名}_六维分析报告.md
5. 报告中必须包含：
   - 基本信息表（含声音特征描述）
   - 六维度评分总览表
   - 18条关系路径信号表
   - 心之壁判定（听力匿名性是默认状态，标注是否仍为"声音匿名型"/已被打破）
   - 核心矛盾与风险

6. **特别注意**：声带健康是语音主播最核心的生理维度——搜索时特别关注"声带""嗓子""失声""手术""休息"等关键词

## 核心评估问题

1. 无视觉层的框架适应性：
   - ③（互动≈内容）在语音主播中是否接近恒等？——这是框架的核心预测
   - ⑥（后台崩塌）在声音匿名性下的检测模式——是否比真人主播更难检测？
   - ⑨（维护成本）是否因无外貌维度而系统性地低于真人主播？

2. 声带消耗验证：
   - ⑦'在语音主播中的表现——声带消耗是否是该群体的主导生理信号？

3. 心之壁：
   - "声音匿名型"心之壁的分布是否如预测为默认状态？
   - 已经"被打破"的案例的共同特征是什么？

4. 平台差异：
   - 不同音频平台的六维评分是否存在系统性偏差？

## 执行说明

1. 语音主播的公开资料比真人主播少——Phase 1 需要有"信息不足排除率会更高"的预期。
2. **声带健康**是语音主播的独特关注维度——在搜索和评分中给予特殊权重。
3. 本验证的核心价值：**语音主播是框架的"无视觉层"极限测试**。与虚拟主播版、真人主播版三份评估报告交叉对比，可以回答：
   - 框架在"有视觉（真人/虚拟）"和"无视觉（语音）"两种前端形态下是否一致？
   - 哪种前-后台结构是框架最适应的？哪种最具挑战？
   - ⑦'（生理消耗）的核心来源从"通用生理"变为"声带消耗"——这是学科锚定的弹性检验。
4. 其余执行规则同虚拟/真人版。
