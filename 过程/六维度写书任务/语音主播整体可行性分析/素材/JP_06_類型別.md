### 类型三：朗読（有声书/朗读）

**代表平台：IRIAM、Pococha、stand.fm、Spoon**

- IRIAM：朗読専用タグあり、声優/ナレーター志望者に人気
- Pococha：朗読配信者が実際に活動、朗読×雑談でファン獲得
- stand.fm：朗読を録音してアーカイブに残せる、メンバーシップ収益化
- Spoon：朗読や声劇が盛んで、音声コンテンツ好きなリスナー層が多い

**收入模式**：投げ銭 + 月額会员 + 限定音声販売

### 类型四：雑談ラジオ（杂谈/聊天电台）

**代表平台：Radiotalk、stand.fm、Spoon、ツイキャス音声配信**

| 特征 | 说明 |
|------|------|
| 内容 | 日常雑談、悩み相談、失敗談、生活改善ヒント |
| 时长 | 数分～2時間 |
| 频率 | 週3回以上 |
| 听众群体 | Radiotalkは20-50代、Spoonは10-20代 |
| 变现 | 投げ銭 + ギフト + パートナープログラム |
| 人气秘诀 | 固定配信時間 + コメント交流 + 共感を生む日常トーク |

### 类型五：音楽/弾き語り（音乐/弹唱）

**代表平台：Spoon、17LIVE、Radiotalk**

- Spoon：音楽/DJセット占上位配信者内容的30%
- 17LIVE：全球154国展开，弹唱配信人气高
- Radiotalk：MUSIC SUNDAY等音乐主题イベント举办

### 类型六：ゲーム実況音声（游戏语音/陪玩）

## 关键发现

1. **ASMR是日本音频内容的最大细分赛道**：MIYU ASMR（314万）超越了绝大多数视频YouTuber。日本ASMR在全球排名中占据重要地位
2. **VTuber的ASMR内容已自成体系**：ホロライブ的白銀ノエル（204万）、猫又おかゆ等，将ASMR与VTuber身份深度融合
3. **声劇（配音广播剧）是日本獨特类型**：ボイコネ和ピカピカ的声劇生态在其他国家几乎不存在
4. **朗読与雑談是最低门槛的入门类型**：不需要ASMR设备、不需要演技，只需"说话"
5. **日本"音声配信"文化成熟度远超其他市场**：50+个音频配信アプリ、完善的事务所体系、与地上波电台的双向联动
6. **YouTube仍是ASMR最大阵地**（视觉辅助音频），但Spoon/Radiotalk等纯音频平台快速成长
