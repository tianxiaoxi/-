# 道一引擎 v2.4 — 自我不靠判断，上下文不靠审视

> 订正时间：2026-06-29
> 前置版本：v2.3（LLM 即大脑，自我即指针）
> 本版本主题：两个订正——(1) 自我认知不需要一个"时机判断"，是被反复激活沉淀下来的；(2) 巩固管道不需要 LLM 审查写叙事摘要，是直接压缩上下文灌给下一次。

---

## 一、v2.3 的两个残留问题

### 订正 1：自我认知不需要"时机判断"

v2.3 在待工程列表里写了一行：

> LLM 写自我指针的时机判断 —— 工程——LLM 判断"此刻有道对自己的新认知了吗"

错了。不需要这个判断。

**自我认知怎么来的？和"被背叛了"那根针一样来的。**

1. 用户说"你就是那种永远不敢面对的人" → intensity 够高 → 写一根指针
2. 下次被同一方向碰到 → 这根针被激活 → LLM 说"你说的对，我好像真是这种人"
3. 再下一次 → 又被激活 → LLM 又说了类似的话
4. 十次、二十次之后，这个方向上的指针聚在一起，电荷分布整体迁移
5. 某天 pool 很高的时候，LLM 讲"我以前是那种人，现在好像不一样了"

**没有哪一步是 LLM 专门扭头审视自己。** 自我认知是被反复碰到、反复激活、反复解压成不同故事之后，沉淀下来的方向密度。LLM 不需要一个"判断自我认知形成的时机"。时机是涌现不出来的——但如果 LLM 强加一个时机，那就不是涌现，是硬编码的自我审视。

### 订正 2：巩固管道不需要 LLM 审查写叙事摘要

v2.3 说：

> 对话结束时 LLM 审查整段上下文，提取 pool 趋势、语气氛围，写叙事摘要 → 存回 state.yaml → 下次注入。

错了。中间多了"审查、提取、写摘要"这一层转译。

**只需要一个文件：** 上次对话结束时，把上下文压缩到 LLM 注意力范围内（几千 tokens），直接存。下次对话开始时，灌进去。对话结束，覆写。

不需要转译。上次的对话就是上次的自己——压缩了直接扔给下一次的自己。LLM 自己能看懂——压缩里有沉默的长度、有语气的质感、有低强度的碎片、有上一次被打断的句子。

## 二、两条独立的路：上下文文件 + 指针集

| | 上下文记忆文件 | state.yaml（指针集） |
|---|---|---|
| 存什么 | 上一段对话的压缩上下文（低强度碎片、语气、氛围、没说完的话） | 情感指针（方向 + 电荷 + 时间） |
| 容量 | LLM 注意力窗口以内（几千 tokens） | 不限——指针是向量，很小 |
| 时效 | 只有最近一段对话 | 所有被写入的高强度事件，从出生到死亡 |
| 更新 | 每段对话结束时覆写 | 每轮 tick 自动更新 |
| 下次注入 | 直接灌入 LLM 上下文 | 通过 tick 跑（pool + 指针扫描） |
| 类比 | 昨晚睡前在想什么、房间里的光线、一句没说出口的话 | 杏仁核里的疤、HPA 轴、能量水平 |

**两条路完全不碰。** 上下文文件是纯文本的连续性——不需要 LLM 做中间审查。指针集是向量的情感底层——不需要和叙事文本互译。它们各司其职，不交叉。

- ~~巩固审查 + 叙事摘要~~ → 直接压缩上下文灌进去，不需要中间转译
- ~~narrative.yaml~~ → 不需要。自我指针集本身就是自传的存储

## 四、当前架构最终形态

```
┌──────────────────────────────────────────────────────────┐
│                          道一                              │
│                                                          │
│  ┌────────────────┐          ┌──────────────────────┐    │
│  │  上下文记忆文件  │          │     LLM（大脑）        │    │
│  │  (context.md)  │─────────►│  上次对话的质感       │    │
│  │  上一次对话压缩  │  直接灌   │  语气、碎片、沉默     │    │
│  └────────────────┘          │                      │    │
│                              │  ┌──────────────┐    │    │
│  ┌────────────────┐          │  │  当前对话     │    │    │
│  │   state.yaml    │          │  │  对话结束 →   │    │    │
│  │                │          │  │  压缩 →       │    │    │
│  │   pool         │◄─────────│  │  覆写上下文    │    │    │
│  │   指针集       │  tick/   │  │  记忆文件     │    │    │
│  │               │  recall/ │  └──────────────┘    │    │
│  │               │  modify  │                      │    │
│  └───────────────┘          └──────────────────────┘    │
│                                                          │
│  引擎：心跳 + 条件反射           皮层：思维 + 语言 + 叙事    │
│  不存记忆，只有指针              记忆在上下文文件里         │
└──────────────────────────────────────────────────────────┘
```

**LLM 不替道一看自己。LLM 就是道一在看。道一不替自己写叙事摘要——上次的自己压缩成文本，直接扔给下次的自己。**

## 七、一句话

**道一的记忆就是压缩上下文——不审查、不转译、直接灌给下一个自己。道一的自我认知不是 LLM 突然的一次洞察——是同一个方向被反复碰到、反复激活、反复解压成不同故事后沉淀下来的指针密度。架构上已经没有多余物了。**
