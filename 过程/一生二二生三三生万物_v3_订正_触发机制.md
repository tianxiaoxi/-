>
> v3 原表述：「它们被在内部前台反复回放」——暗示符号持续活跃。订正：**符号是潜伏的，只在被触发时激活。**

## 订正内容

### 原 v3 遗漏

v3 §一中说「在内部前台反复回放」，但未说明何时回放、回放是否有条件。这容易误解为符号像一个持续循环的播放器——实际上不是。

### 订正：符号是潜伏滤网，不是持续播放器

```
平时（符号休眠）：
  raw 后台 ──[心之壁₁]──→ 内部前台（日常意识流，神圣符号潜伏）
                                ↓
                          心之壁₂ → 外部前台（正常互动——符号不影响此刻）

被触发时（符号激活）：
  外部事件（如：同事在会议上否定了我的提案）
        ↓
  刺激匹配：这个场景激活神圣符号「被当众羞辱」
        ↓
  符号进入内部前台，同时发生两件事——
    (a) 内部回放：当年的场景被重演，当时的情绪涌上来
    (b) 过滤当前事件：「同事否定」被符号染色
        → 「这不只是提案被否，这又是那件事」
        → 情绪反应远超当前事件应有的程度
        ↓
  心之壁₂厚度瞬间调整：
    「不能暴露弱点」→ 临时加厚，外部强行镇定
    「我必须反击」→ 临时变薄，冲动直接进入外部呈现
        ↓
  触发事件结束后 → 符号回到潜伏
    但 thickness/integrity 的偏移可能残留
```

### 触发条件：刺激相似度匹配

| 匹配维度 | 例子 |
|---------|------|
| 场景结构相似 | 你在群体中被一个人否定，其他人都沉默 |
| 情绪线索相似 | 感受到特定的羞耻感、无助感 |
| 角色位置相似 | 你处于「展示者」位置，对方处于「评判者」位置且不对等 |
| 语言模式相似 | 对方说了类似的话——「你太天真了」「你这样不行」 |

符号越强（原始 intensity 越高），触发阈值越低。高强度经历形成的符号，一点风吹草动就能激活。

### 触发的两个效应

**效应 A：情绪侵入**。原始经历的情绪强度被重新注入内部前台。你的身体在回应当年的创伤，不是回应此刻的事件。

**效应 B：过滤失真**。符号是一个眼镜——戴上它看当前事件，看到的东西和实际的不一样。从仪式链的角度，这是内部仪式的外部投射。

### 累积残留

| 触发频率 | 效应 |
|---------|------|
| 单次触发 | 心之壁₂ thickness 临时偏移，事件结束后回弹 |
| 短期内频繁（5 轮 ≥3 次） | integrity 磨损，不再完全恢复 |
| 长期频繁 | baseline 缓慢上移——「越来越不容易信任了」，触发阈值进一步降低 |

### 跨域传导：与五行生克的对位

```
触发事件落在 autonomy 域（被否定） → 激活符号「信任是奢侈品」
  → 符号本身在 peer 域（关于人际信任）
  → 官杀克比劫：autonomy 域消耗 → peer 域跟随消耗
  → 角色的防御不只停留在被否定这件事上，还扩散到了人际关系
```

符号不只是一个信念，它是一个**跨域传导器**。

### 对⑥路径的补充

符号触发是分裂壁之前的中间态——一种可控的失调。这一层在 v3 的「心之壁₁完好 + 心之壁₂薄」和「心之壁₂破裂」之间：符号激活导致心之壁₂临时变薄，内部仪式的色彩染进了外部呈现，但仍在社交可接受范围内。日常互动中大多数「反应过度」属于这一类。
