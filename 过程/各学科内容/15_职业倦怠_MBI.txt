# 职业倦怠 (Burnout) — Maslach Burnout Inventory (MBI)
# 适用分析维度：复盘与刻意练习

## 一、核心理论框架

Maslach 的职业倦怠（Burnout）模型是公认的倦怠研究金标准。倦怠不是"累了"，而是一种由长期工作压力导致的、包含三个维度的综合征。

### 三个核心维度
1. **情绪耗竭 (Emotional Exhaustion)** — 感到情绪资源被耗尽、疲惫不堪、没有能量面对新一天的工作。这是倦怠的"能量维度"
2. **去人格化/玩世不恭 (Depersonalization / Cynicism)** — 对工作对象（对主播来说是粉丝/内容/平台）变得冷漠、疏离、消极、甚至厌恶。这是倦怠的"态度维度"
3. **个人成就感降低 (Reduced Personal Accomplishment)** — 感到自己不再有效能、工作没有价值、自己做不好、对未来悲观。这是倦怠的"评价维度"

### 倦怠的发展阶段
```
热情期 → 停滞期 → 挫折期 → 冷漠期 → 倦怠期（三个维度全部出现）
```

### 关键区分
- 倦怠 ≠ 累（累睡一觉就好，倦怠睡一觉还是那样）
- 倦怠 ≠ 抑郁（倦怠是工作相关的；抑郁是泛化的）
- 倦怠 ≠ 压力（压力是"太多了"，倦怠是"不够了"——不够能量、不够关心、不够自我效能）

### 倦怠的6个风险因素（工作匹配模型）
1. 工作负荷过重
2. 缺乏控制感
3. 回报不足
4. 社群破裂
5. 缺乏公平感
6. 价值观冲突

## 二、AI 判断逻辑体系

### 维度1：情绪耗竭判断
**判断对象**：主播/创作者是否感到情绪资源被消耗殆尽

| 耗竭阶段 | 判断特征 | AI 检测方法 |
|---------|---------|-----------|
| 疲劳期 | "今天有点累""昨晚没睡好""这周忙"——生理疲劳为主，休息可恢复 | 疲劳归因于具体原因（没睡好/事情多），有可逆性 |
| 耗竭前兆 | "最近总觉得很累""不知道为什么老是这么累"——疲劳开始脱离具体原因 | 疲劳归因模糊化——"不知道为啥累就是累" |
| 耗竭期 | "睡多久都累""不想起床""面对观众就觉得累"——休息无法恢复 | 疲劳不再对休息响应——这是倦怠与普通过劳的区分点 |
| 崩溃期 | "我撑不住了""我做不动了""让我休息吧"——公开表达无力继续 | 公开求援信号——功能已经受到影响 |

**AI 判断要点**：情绪耗竭的核心判断标准是"疲劳是否对休息有响应"——休息后能恢复 = 过劳（可逆），休息后不能恢复 = 倦怠性耗竭（需更深度干预）。检测主播的"能量语言"时间序列——看"累"的表达频率是否在上升、归因是否在变模糊。从"我累了是因为XX具体原因"到"我就是累"的归因变化，是耗竭深化的关键信号。

### 维度2：去人格化/玩世不恭判断
**判断对象**：主播是否对粉丝/内容/工作产生了疏离和冷漠

| 去人格化阶段 | 判断特征 |
|------------|---------|
| 健康投入期 | 对粉丝有关心、对内容有热情、把粉丝当作"具体的人" |
| 距离初期 | 开始用"他们""观众"代替"大家""咱们"——从"我们"变成"我vs他们" |
| 玩世不恭期 | 私下吐槽粉丝/内容/平台的频率上升；使用嘲讽、冷漠语气提及工作对象 |
| 物化期 | 把粉丝看作"数字""收益来源"——"今天来了多少人头""这些韭菜"；失去对个体的尊重和共情 |
| 对立期 | 公开与粉丝/观众发生冲突；表达不做这行的意愿；"烦死了""受够了" |

**AI 判断要点**：去人格化是倦怠中最危险的维度——因为一旦主播开始厌恶粉丝，粉丝是能感觉到的。检测"人称指称的变化"——从"我的观众""大家""咱们家的人"变为"他们""那些人""这些/那些XX"，人称变化背后是情感距离变化。检测"吐槽的温度变化"——偶尔吐槽是正常的，但吐槽从"调节情绪"变成"表达厌恶"时，就是从正常到倦怠的转折点。

### 维度3：个人成就感降低判断
**判断对象**：主播是否感到效能丧失、价值感消退

| 成就感状态 | 判断特征 |
|----------|---------|
| 健康成就期 | "今天做得不错""我进步了""这个内容我满意"——有清晰的内部成就感 |
| 怀疑初期 | "还行吧""说不上来""我也不知道好不好"——自我评价开始模糊 |
| 降低期 | "做得不好""退步了""不如以前了"——明确的自我否定叙事 |
| 虚无期 | "好又怎样、不好又怎样，没意义""反正也没人真在意"——不仅否定能力，还否定价值 |
| 绝望期 | "我不适合干这个""我该退了""换个人做更好"——退出叙事出现 |

**AI 判断要点**：个人成就感降低的判断重点是"自我评价是否越来越依赖外部验证"——健康时"我觉得好就是好"，倦怠后"只有他们说好我才能安心一会儿"。检测"自我评价语言"的变化——从内部标准（"我很满意""达到了我的标准"）退到外部标准（"他们应该还行吧""反正有人看就行"），再从外部退到无标准（"无所谓了"）。这个退化轨迹是成就感降低的典型路径。

### 维度4：倦怠三合一的综合判断

倦怠的三个维度可以不同步出现，但"三合一"才构成完整的倦怠综合征：

| 维度组合 | 状态命名 | 判断特征 |
|---------|---------|---------|
| 仅情绪耗竭 | 过劳状态 | 累但依然关心、依然觉得自己可以——只是能量跟不上 |
| 仅去人格化 | 异化状态 | 不累也能做，但已经不在乎——"我就是在做工" |
| 仅成就感降低 | 自我怀疑状态 | 能量还有、也还关心，但已经开始质疑自己行不行 |
| 耗竭+去人格化 | 严重过劳 | 能量耗尽 + 对工作的爱也耗尽——高离职风险 |
| 耗竭+成就感降低 | 透支型倦怠 | 累 + 觉得自己不行——"我已经被掏空了但还是做不好" |
| 去人格化+成就感降低 | 意义崩塌型 | 不在乎 + 没价值——"这工作没有意义，我也不擅长" |
| 三合一 | 完全倦怠 | 累 + 不在乎 + 觉得自己不行——需要结构性干预 |

**AI 判断要点**：三维度的组合分析比单维度得分更重要——因为不同组合需要不同干预策略。如"过劳状态"需要的是休息和减负，而"意义崩塌型"需要的是重新找到工作与自己价值观的连接。分析三个维度出现的先后顺序——通常情绪耗竭最早出现，其次是去人格化，最后是成就感降低。如果在早期认出第一个维度的信号，可以在发展成三合一前干预。

### 维度5：倦怠的6个风险因素匹配判断
**判断对象**：在主播的工作环境中，存在哪些倦怠风险因素

| 风险因素 | 判断特征 | 高风险信号 |
|---------|---------|-----------|
| 工作负荷 | 直播/内容时长、频次、准备时间是否超过可持续水平 | "每天除了睡觉就是直播""根本没有自己的生活" |
| 控制感 | 对内容方向、节奏、合作选择的自主权 | "被流量绑架""被观众需求牵着走""不得不做不喜欢的内容" |
| 回报不足 | 收入、认可、成长感是否匹配付出 | "付出和回报不成正比""刷了很多但没人看" |
| 社群破裂 | 粉丝关系恶化、核心团队分裂、孤立无援 | "没人理解""铁粉都走了""团队里只有我一个人在扛" |
| 公平感 | 对比他人（同行）后产生的不公平感 | "别人随便搞搞就爆了，我这么用心没人看" |
| 价值观冲突 | 做的事与自己相信的价值观冲突 | "这不是我想要的""我讨厌现在的自己""为了流量什么都做" |

**AI 判断要点**：风险因素分析是倦怠的"预防工具"——不等倦怠发生，就能看出哪些因素在积累风险。关键是"差距感"——主播想要的与实际得到的之间的差距。"价值观冲突"是最深层、最难修复的风险因素——当一个主播开始说"这不是我想要的"，倦怠已经深入到认同层面。

### 维度6：倦怠恢复的可行性判断

| 恢复阶段 | 判断特征 | 所需干预 |
|---------|---------|---------|
| 可自行恢复 | 单维度轻度倦怠，对休息有响应 | 休息+减负 |
| 需轻度干预 | 两维度中度倦怠，需要外部帮助才能恢复 | 减少工作量+找回成就感来源+修复社群关系 |
| 需深度干预 | 三合一，已经影响正常功能 | 暂停工作+专业帮助+结构性调整 |
| 可能不可逆 | 持续时间极长，对任何干预都无反应 | 可能到了该转型的阶段，强行回到原赛道只会重复倦怠 |

**AI 判断要点**：恢复力判断的关键是"是否还能找到工作的意义"——如果能找到"为什么还要做"的理由，恢复就有希望。分析语言中"未来的我"的表述——还有未来版本自己的想象，说明还有内在动力。完全倦怠的语言里，"未来的我"是空白的。

## 三、综合判断框架

```
倦怠程度 = (情绪耗竭得分 × 去人格化得分 × 成就感降低得分)^(1/3)

其中各维度得分（0-10）基于上述行为信号综合判断

倦怠等级：
  0-2：健康状态——三维度均无异常
  2-4：过劳预警——单一维度出现轻微异常
  4-6：倦怠前期——两个维度出现中度异常
  6-8：显著倦怠——三个维度全部出现
  8-10：严重倦怠——三合一且影响功能，需暂停工作

风险累积指数 = 6个风险因素中存在数量 / 6

恢复前景 = 内在动机存续度 × 社会支持可及性 × (1 - 倦怠持续时间/恢复窗口)
```

**AI 使用要点**：
1. 倦怠是渐进的——不要等到三合一再干预，在第一个维度出现信号时就要行动
2. "累但睡一觉就好"和"累但睡一觉还是累"——这是过劳与倦怠的分水岭
3. 去人格化的最早信号是人称变化——从"他们是我最重要的人"变成"他们就是观众而已"
4. 成就感降低的修复不能靠"别人夸你"——外部认可能缓解但不能治愈，需要重建内部标准
5. 最危险的倦怠信号不是"我好累"，而是"我不在乎了"——当一个人停止在乎，已经离退出不远了
