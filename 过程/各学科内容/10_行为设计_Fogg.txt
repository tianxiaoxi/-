# 行为设计 (Behavior Design) — BJ Fogg
# 适用分析维度：综合总结

## 一、核心理论框架

Fogg 的行为模型认为，一个行为是否发生取决于三个要素是否同时满足：

### Fogg Behavior Model: B = MAP
- **B (Behavior)** — 行为是否发生
- **M (Motivation)** — 动机：做这件事的意愿强度
- **A (Ability)** — 能力：做这件事的容易程度
- **P (Prompt)** — 提示：触发行为的信号

只有当 M、A、P 三者同时"过线"时，行为才会发生。

### 核心洞察
1. **动机是波动且不可靠的** — 动机有时高涨有时低落，不能靠它来驱动长期行为
2. **能力比动机更可依赖** — 把事情变得足够简单，即使动机不高也能做到
3. **提示是启动键** — 没有提示，再高的动机和能力都不会转化为行动
4. **微小习惯** — 从"小到不可能失败"的行为开始，逐步构建
5. **成功感积累** — 每一次完成后的"我做到了"的感觉是继续下去的关键燃料

### 行为设计的黄金法则
```
让对的行为更容易做 (Make it easy)
让错的行为更困难做 (Make it hard)
```

### 微小习惯的三步
1. 选一个"小到不会失败"的行为
2. 把它锚定在一个已有的习惯之后（作为提示）
3. 完成后立刻庆祝（创造积极情绪锚定）

## 二、AI 判断逻辑体系

### 维度1：动机水平与波动性判断
**判断对象**：主播/粉丝的行为驱动力是否稳定

| 判断信号 | 稳定动机特征 | 波动动机特征 |
|---------|------------|------------|
| 行为一致性 | 有规律的行为模式——无论状态好坏都能维持基本动作 | 行为忽多忽少、忽好忽坏，与情绪状态强相关 |
| 低动机补偿 | 即使"不想做"也有"最小化版本"可执行 | 不想做就彻底不做、状态差就摆烂 |
| 动机来源 | 来自习惯/身份/系统而非情绪爆发 | 来自情绪爆发——兴奋时拼命做，低落时什么都不做 |
| 恢复速度 | 中断后能快速恢复（因为有系统支撑） | 中断后难以恢复（因为全靠意志力/情绪） |

**AI 判断要点**：判断动机稳定性不是看"平均动机高低"，而是看"行为的时间分布方差"——行为在时间线上分布的均匀程度。高波动 = 动机驱动型（不可靠），低波动 = 系统驱动型（可靠）。检测"最小化行为"的存在——在状态最差的日子里，有没有一个"再差也能完成的底线动作"。

### 维度2：能力/简易度判断
**判断对象**：对于目标行为，执行力门槛是否足够低

| 判断维度 | 低门槛特征 | 高门槛特征 |
|---------|----------|-----------|
| 时间门槛 | 目标行为只需极少时间（5分钟可完成） | 目标行为需要大块时间 |
| 技能门槛 | 不需要特殊技能，现有能力即可完成 | 需要学习新技能才能开始 |
| 启动摩擦 | 几乎不需要准备、打开就能做 | 需要大量准备（设备、场地、材料） |
| 心理门槛 | 不触发焦虑/抗拒/完美主义 | 一想到要做就焦虑、想拖延 |
| 环境门槛 | 环境已经为做这件事优化好了 | 需要先改造环境才能动手 |

**AI 判断要点**：能力判断的核心是"行为是否被设计得足够简单"——不是指责"你不够努力"，而是检查"行为设计是否有问题"。如果一个应该持续发生的行为没有持续发生，先看A（能力/简易度）是否有问题，而不是先归因于M（动机/意志力）。分析主播/粉丝在试图养成习惯或完成目标时，遇到的是什么类型的"门槛"——时间、技能、心理、环境，哪个在挡路。

### 维度3：提示有效性判断
**判断对象**：行为触发机制的可靠性

| 提示类型 | 有效提示特征 | 无效提示特征 |
|---------|------------|------------|
| 习惯锚定 | 绑定在一个无疑会发生的已有习惯之后（"刷完牙后冥想1分钟"） | 绑定在一个不稳定的行为之后（"有空的时候"） |
| 环境提示 | 环境中的视觉/听觉信号自然触发行为 | 依赖记忆——"我记得要做XX"难以持续 |
| 社交提示 | 其他人的行为/提醒稳定触发自己的行动 | 社交提示不稳定或不及时 |
| 时间提示 | 固定时间点的行为有规律节奏 | 时间不固定、想起来才做 |

**AI 判断要点**：如果一个应该发生的行为没发生，不一定是你不想做，很可能是"提示没响"。分析行为中断是否跟随提示的消失——一个稳定提示后跟着一个稳定行为→提示消失→行为消失，说明问题是提示端而非动机端。

### 维度4：微小习惯与成功感积累判断
**判断对象**：是否在通过"小成功"建立行为飞轮

| 判断信号 | 微习惯成功特征 | 微习惯缺失特征 |
|---------|--------------|--------------|
| 起点设置 | 初始目标"小到可笑"——低到不可能失败 | 初始目标就是终极目标、一步到位 |
| 扩大方式 | 在稳固的基础上自然扩大，不强迫 | 急于求成、刚做到小目标就急吼吼翻倍 |
| 庆祝行为 | 完成后有积极情绪锚定（自我肯定、小小奖励） | 完成后无任何正面反馈——"这只是基本的、没什么好高兴的" |
| 失败反应 | 没做到时不自我攻击——"今天没做没关系，明天继续" | 没做到时自我否定——"我果然做不到"→ 行为彻底放弃 |
| 身份叙事 | "我是一个每天会XX的人"的身份认同逐步建立 | 行为始终是"我要努力做到的事"而非"我是这样的人" |

**AI 判断要点**：判断微小习惯是否成功运作，不是看行为是否保持，而是看"身份叙事"是否开始变化——从"我在努力坚持做XX"变成"我就是一个会做XX的人"。身份叙事的变化是行为设计中最重要的跃迁信号。分析"失败后的处理方式"——微习惯系统好的表现是"滑倒了站起来，拍拍土继续走，不给自己加戏"。

### 维度5：行为设计的系统性判断
**判断对象**：行为改变是依赖个人意志力还是系统设计

| 系统 vs 意志力 | 系统驱动特征 | 意志力驱动特征 |
|--------------|------------|--------------|
| 依赖对象 | 依赖环境设计/习惯锚定/提示机制 | 依赖"咬牙坚持""自律" |
| 稳定性 | 环境稳定则行为稳定 | 情绪/状态波动则行为波动 |
| 可复现性 | 在不同情境下都能复现 | 只在状态好的时候能做 |
| 抗干扰 | 外界干扰不轻易打乱行为 | 一点干扰就打乱全盘 |
| 日常语言 | "到点了，该做XX了"（被系统推着走） | "今天得坚持做XX"（用意志力扛着走） |

**AI 判断要点**：Fogg 的终极判断标准是——"如果你今天的动机为零，你还能完成这个行为的最小版本吗？"能 = 系统设计到位；不能 = 还在靠意志力。分析语言中"被推着走"和"扛着走"的区别——"到点了该播了"（系统推动，低摩擦）vs"打起精神来播吧"（意志力驱动，高摩擦）。

## 三、综合判断框架

```
行为稳定度 = B = M × A × P

其中：
- M 稳定度 = 1 - 行为波动方差 / 行为均值（越接近1越稳定）
- A 简易度 = 实际执行难度 / 理应执行难度（越接近0越简单）
- P 可靠度 = 有效提示次数 / 行为目标次数

提升顺序（Fogg优先序）：
  1. 先降门槛（A）：把行为变简单
  2. 再设提示（P）：找到可靠的触发点
  3. 最后调动机（M）：在前两者就位的基础上再考虑动机激发

行为设计健康度 = 系统驱动占比 × 微小习惯落地率 × 身份叙事进化度

行为问题排查优先级：
  如果行为没发生 → 先查P（提示响了没）→ 再查A（是否太难）→ 最后查M（是否不想）
  （80%的行为问题出在A或P，而非M）
```

**AI 使用要点**：
1. 行为设计的核心心法是"不要相信意志力"——好的行为设计让人在意志力最低时也能完成
2. 排查行为问题时永远先问"能不能让它更简单"而不是"你能不能更努力"
3. 微小习惯的精髓是"行为→庆祝→身份"——先做成、再开心、最后认同自己是这样的人
4. 动机是短期燃料，系统是长期引擎——行为设计就是帮人从燃动机转向建引擎
