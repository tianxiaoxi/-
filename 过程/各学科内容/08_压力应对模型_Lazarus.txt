# 压力应对模型 (Transactional Model of Stress and Coping) — Richard Lazarus
# 适用分析维度：个人状态

## 一、核心理论框架

Lazarus 认为，压力不是事件的客观属性，而是个体与环境的"交互产物"——同一事件对不同人是不同压力。核心在于两次评估和后续应对。

### 三步过程
1. **初级评估 (Primary Appraisal)** — "这件事对我意味着什么？"
   - 无关的 → 良性/积极的 → 有压力的
   - 压力类细分：威胁（预期损害）、挑战（可克服的困难）、伤害/损失（已发生的损害）

2. **次级评估 (Secondary Appraisal)** — "我能应对吗？"
   - 评估自己拥有的资源和应对能力
   - 如果"需求 > 资源"→ 压力反应
   - 如果"资源 > 需求"→ 挑战反应

3. **应对策略 (Coping)** — "我做什么？"
   - 问题聚焦应对：直接解决压力源
   - 情绪聚焦应对：调节情绪反应
   - 意义聚焦应对：重新解释/找意义

### 核心公式
```
压力体验 = 环境需求 / 感知资源

如果将此评估为"挑战" → 激发积极应对 → 成长
如果将此评估为"威胁" → 激发防御应对 → 消耗
```

## 二、AI 判断逻辑体系

### 维度1：初级评估模式判断
**判断对象**：主播/创作者面对情境时，偏向将其评估为什么类型

| 评估类型 | 语言特征 | AI 检测方法 |
|---------|---------|-----------|
| 威胁型评估 | "完了""出事了""怎么办""扛不住了"；关注可能的负面结果 | 检测对未来的灾难性预期与无力感表达 |
| 挑战型评估 | "试试看""应该可以""有意思""有点难但有办法"；关注如何攻克 | 检测问题解决导向的表达和适度的困难认知（承认难但不恐慌） |
| 伤害/损失型评估 | "已经晚了""没用了""回不去了"；关注已发生的不可逆损失 | 检测过去时态 + 不可逆语义 + 放弃努力的态度 |
| 良性/积极型评估 | "还好""没事""正常""不用担心"；事件不被看作压力源 | 检测风轻云淡的态度和事件降级表述 |
| 无关型评估 | "跟我没关系""不用管""算了"；主动划清边界 | 检测边界设定语言和主动的"与我无关"判断 |

**AI 判断要点**：初级评估是AI判断压力应对的核心起点——同一个事件（如掉粉、被黑、收入下降），不同评估取向会导致完全不同的应对路径。分析主播描述困境时的"归因方向"：是往"我面临一个需要解决的挑战"走（挑战型），还是往"这件事会毁了我"走（威胁型）。归因方向的差异是判断压力走向的最早信号。

### 维度2：次级评估——感知资源能力判断
**判断对象**：主播/创作者认为自己拥有的应对资源

| 资源类型 | 资源充裕的语言特征 | 资源匮乏的语言特征 |
|---------|------------------|------------------|
| 个人能力 | "我可以学""我有经验""我应该能处理" | "我不行""我没这个能力""我只能这样了" |
| 社会支持 | "我有XX帮我""大家会支持我的""还有人站在我这边" | "我一个人扛""没人帮我""谁都靠不住" |
| 物质资源 | 财务/设备/时间等方面的"有"感 | "没钱""没时间""没条件" |
| 心理韧性 | "经历过更难的""这不算什么""我能扛" | "我已经撑不住了""到极限了""再这样我会崩" |
| 信息/知识 | "我了解""我知道怎么办""我有方案" | "我不知道""完全没头绪""没人教过我" |

**AI 判断要点**：次级评估的关键是"感知资源"而非"客观资源"——一个人觉得有人帮和客观上有人帮是不同的，前者才影响压力反应。分析主播在描述困难之后是否接上"但是"型的资源陈述（"虽然很难，但我有XX"），这种结构是次级评估偏积极的信号。最危险的信号是"资源清单为零"——即主播在表达困难后没有任何能力/支持/办法的表达。

### 维度3：应对策略类型判断
**判断对象**：主播采取什么方式应对压力

#### 问题聚焦应对
| 判断信号 | 有效特征 | 无效/低效特征 |
|---------|---------|-------------|
| 分析问题 | 冷静分析问题原因："为什么会出现这个情况""根本原因是XX" | 跳过分析直接行动，或过度分析陷入瘫痪 |
| 制定计划 | "接下来我打算XX""我的计划是XX" | 没有计划或计划明显不切实际 |
| 执行行动 | 描述实际采取的行动步骤，有明确的"做了XX" | 只有说"我会XX"但从无后续 |
| 寻求帮助 | "请教了XX""看了XX的方法"——实际求助行为 | 只说"没人帮我"但不主动求助 |

#### 情绪聚焦应对
| 判断信号 | 适应性特征 | 非适应性特征 |
|---------|----------|------------|
| 情绪宣泄 | 适度宣泄后情绪平复、回到理性 | 宣泄升级、越宣泄越激动/越低落 |
| 转移注意 | 主动去做其他事调节情绪，转移后情绪改善 | 只是逃避、转移后问题还在且更焦虑 |
| 寻求安慰 | 接受安慰后情绪好转、有力量继续 | 依赖安慰、没有安慰就无法正常运作 |
| 正向重评 | "这其实也让我学到了XX"——从负面中找到正面意义 | 盲目乐观、回避问题实质 |
| 情绪回避 | — | "不去想""假装没事"——长期导致问题发酵 |

#### 意义聚焦应对
| 判断信号 | 有效特征 |
|---------|---------|
| 成长叙事 | "这段经历让我成长了""经过这件事我变得更XX" |
| 价值观重评 | "以前觉得重要的事现在觉得不重要了"——重新排序人生优先级 |
| 利他转化 | "自己经历过所以想帮别人""希望我的经历能给同样处境的人力量" |

**AI 判断要点**：应对策略的判断不是看做了什么，而是看"做了之后呢"——情绪改善了没？问题推进了没？长期的应对模式是否在三种聚焦之间灵活切换（只有一种策略通常是不够的）。最高质量的应对是"问题聚焦+意义聚焦"双管齐下——既解决问题又赋予意义。

### 维度4：压力-应对的动态循环判断

压力应对不是单次事件，而是一个持续循环：

```
情境 → 初级评估 → 次级评估 → 应对 → 结果 → 重新评估 → ...
```

| 循环阶段 | 健康信号 | 不健康信号 |
|---------|---------|-----------|
| 评估→应对延迟 | 短暂停顿后采取行动 | 长时间反复评估不行动（反刍思维） |
| 应对→结果反馈 | 能根据结果调整策略 | 应对无效也不调整，反复用同一种无效策略 |
| 结果→重新评估 | 成功经验提升下次的次级评估信心 | 失败经验降低下次的次级评估→形成下行螺旋 |
| 多事件关联 | 不同压力事件之间能有效隔离 | 一个压力事件的负面影响扩散到其他领域 |

**AI 判断要点**：最关键的动态指标是"上下行螺旋"——连续的应对成功会逐渐提升次级评估的信心，形成上行良性循环；连续的应对失败会侵蚀次级评估，形成下行恶性循环。检测"评估基调的变化趋势"：最近的压力事件评估，比过去同类型事件的评估更积极还是更消极？

### 维度5：压力累积效应判断

| 累积阶段 | 特征 | 预警信号 |
|---------|-----|---------|
| 正常应对 | 压力事件逐一处理，有反应有恢复 | 压力过后状态恢复 |
| 压力积累 | 多个压力事件叠加，上一件还没处理完下一件就来了 | "一件接一件""喘不过气"的累积表达 |
| 资源透支 | 不再有精力做次级评估——直接跳入应激反应 | "我现在不想思考""就这样吧"的认知关闭信号 |
| 崩溃边缘 | 小事也能触发强烈反应（因为资源已耗尽） | 对小事过度反应——"压死骆驼的最后一根稻草"模式 |

## 三、综合判断框架

```
压力应对效能 = (挑战型评估占比) × (感知资源充足度) × (应对策略多样性)

其中：
- 挑战型评估占比 = "这是挑战"类评估 / 所有压力评估
- 感知资源充足度 = 5类资源中有表达的数量 / 5
- 应对策略多样性 = 实际使用了3种聚焦中的几种 / 3

螺旋方向判断：
  上行螺旋：连续3次压力事件的应对效能 ≥ 前次
  平行螺旋：连续3次效能持平
  下行螺旋：连续3次效能 < 前次

干预建议触发条件：
  - 下行螺旋持续 ≥ 3次事件
  - 感知资源充足度 < 0.2（即5类资源中几乎一种都感觉不到）
  - 威胁型评估占比 > 70%
```

**AI 使用要点**：
1. 压力不是客观的——同一件事，评估为"挑战"就是成长机会，评估为"威胁"就是消耗
2. 初级评估偏向是AI最应该关注的第一信号——"完了"和"有意思"两个词背后是截然不同的压力轨道
3. 应对策略不用"正确"与否来评判——用"有效"与否、以及"是否有多样策略可切换"来评判
4. 下行螺旋一旦形成，需要外力打断——指望当事人自己逆转螺旋是需要额外资源的（而她此时恰好资源不足）
