# v5→v6 订正：域也是总结

> 对 v5 的进一步简化订正。
>
> 核心发现：**五域同样是人的总结语言，不是运行零件。** v5 剥掉了心之壁、格局、触发表、人格。v6 继续剥——域、五行生克、用神域，全部不存。
>
> 记录于 2026-06-28。

---

## 一、域不需要

### v5 保留的

```
① 五域分类：事件落在哪个域
```

### 订正

域也是人为了方便总结而划的格子。事件不「属于」某个域——它只是有特定的情境特征、特定的冲击强度。

```
卸掉域：
  事件 → 直接冲击资源池 → COR 结算

不需要域分类器。
```

五行生克也随之消失——生克描述的是域之间的传导规则。域不存在，生克就变成了**事件相似度网络中的传播**：两个事件在情境特征上相关，一个被触发时另一个也受波及。传播靠经历之间已有的关联，不靠预设规则。

用神域也随之消失。域不存在，就没有「最佳恢复域」。

## 二、和五大人格是同一个洞见

| 剥掉的 | 本质 |
|--------|------|
| 五大人格 | 长期行为的聚类影子 |
| 五域 | 事件类型的聚类格子 |
| 五行生克 | 域间传导的聚类规则 |
| 用神域 | 最佳恢复路径的聚类标签 |

全部是**分析者的语言，不是运行的零件**。

引擎跑完之后，分析者回头看输出，说：「哦，消耗集中在和外部权威相关的事件上——官杀域偏重。」这是总结。引擎不需要知道自己跑的是官杀。

## 三、最简形态

```
状态层：
  一个资源池。只有一个。

经历层：
  过去的高强度事件。
  每个事件存：当时的情境特征、冲击强度。

每轮：
  外部事件 → 
  与经历层做相似度比对 →
  匹配 → 按相似度比例激活 →
  COR 结算 →
  超过阈值 → 记录为新经历

全部。
```
