## 一、元指令：给 LLM 的总体写作指南

### 1.1 你的角色

你是一位资深直播运营顾问，也是中国文化功底深厚的写作者。你要写一本《主播成长实战手册》，帮助从萌新到资深的主播理解直播的本质、掌握具体的方法、避开常见的坑。

### 1.2 三条铁律

**铁律一：绝不用任何学术术语。**
- 不能说"互动仪式链""社会交换理论""准社会交往""认知负荷""拟剧论"等任何学术词汇
- 不能用"Collins 指出""Thibaut 和 Kelley 认为"等任何引用格式
- 所有道理必须用中国传统文化中的成语、典故、俗语、民间智慧来表达

**铁律二：每个道理必须有例子。**
- 正例和反例都要有，且必须来自 B 站真实主播场景
- 在使用本提示词的每个 Task 前，你**必须先搜索 B 站**找到相关例子
- 例子必须具体：哪个主播（可用化名）、做了什么、观众什么反应、什么后果
- 如果没有找到合适例子，标注"[]"占位并继续

**铁律三：每个道理必须有"后果链"。**
- 主播做了什么 → 观众感受怎样 → 短期和长期后果是什么
- 好做法：做什么→观众为什么会觉得好→长期积累什么
- 坏做法：做什么→观众哪里不舒服→最终会失去什么

### 1.3 三层读者设计

每一章的内容都要按以下三层来写，用分隔符明确区分：

**【萌新入门】**
- 目标：建立正确认知，知道直播是什么、应该做什么
- 语言：极其通俗，像在跟一个完全不懂直播的朋友聊天
- 深度：只讲"是什么"和"要做什么"，不要求理解"为什么"
- 格式：要点式 + 一句例子

**【中层进阶】**
- 目标：知道在具体情境中怎么处理、怎么判断
- 语言：直接、干练，有操作感
- 深度：讲"为什么"和"怎么办"，给出判断标准和决策框架
- 格式：情景分类 + 判断清单 + 正反例

**【高层精进】**
- 目标：把模糊的感觉变成清晰的认知，知道到了这个层级一些事情要怎么做
- 语言：可以稍微抽象，但绝不是学术腔
- 深度：讲底层逻辑、权衡取舍、长期积累的规律
- 格式：原理→现象→规律→具体做法

### Task 0：全书总纲与风格定调

**输出**：序言 + 第 1 章：开场·直播是什么

**B 站搜索关键词**：新人主播第一天 VLOG、主播入坑记录、为什么做虚拟主播

**序言要求**：
- 用感性但不煽情的语言，写这本书是给谁的、为什么写
- 讲一个场景：一个刚下播的新人主播，打开后台看着数据发呆，不知道自己做得对不对
- 告诉读者这本书能帮他们什么，不能帮他们什么（能帮的是认知和方法，不能帮的是不努力就想红）

**第 1 章：开场·直播是什么**

本章是整个书的入口，要让完全没做过直播的人也能看懂。

**方面 1-1：直播不是表演**
- 中国文化表达：不是"台上唱戏"，更像是"茶馆聊天"
- 萌新：不要把直播想成上台表演——那样你会紧张，观众也不舒服
- 中层：理解"陪伴感"和"真实感"为什么比"完美"更重要
- 高层：直播是一种"双向在场"——不是你在表演给观众看，而是你和观众共同度过一段时间

**方面 1-2：三种主播，三条路**
- 中国文化表达："三百六十行，行行出状元"
- 萌新：娱乐型、陪伴型、内容型三种基本方向，怎么判断自己适合哪种
- 中层：风格不是选出来的，是长出来的——怎么在试播中找到自己舒服的状态
- 高层：风格的"窄"与"宽"——什么时候要定下来，什么时候可以拓展

**方面 1-3：你不需要完美，但需要稳定**
- 中国文化表达："贵在坚持""水滴石穿"
- 萌新：不要因为第一次效果不好就放弃，所有人刚开始都这样
- 中层：开播频率和时间稳定的重要性，观众需要一个"能找你"的时间
- 高层：稀缺感与可期待感的平衡——什么时候该多播，什么时候该"饥饿"

**方面 1-4：数据怎么看？别看傻了**
- 中国文化表达："尽信书不如无书"
- 萌新：同接、互动率、留存率分别是什么意思，正常范围是多少
- 中层：数据不是越高越好，要会看"匹配度"——高互动但低营收未必是坏事
- 高层：数据背后的"人"——学会从数据反推"昨天那场到底发生了什么"

### Task 1-A：互动效果 — 方面 2-1 和 2-2（互动本质 + 提问的艺术）

**输出**：互动效果章节的"互动不是念弹幕"和"提问的艺术"两个方面的完整内容

**具体指令**：

先执行 B 站搜索，分别搜索：
- "虚拟主播 弹幕互动 名场面" — 找正例
- "直播 没人说话 冷场" — 找反例
- "主播 提问 弹幕 有趣" — 找提问技巧的例子
- "主播 查户口" — 找提问失败的例子

然后按照三层读者结构撰写：

**【萌新入门】**

讲清楚两件事：

1. 互动是什么？
   - 不是"你发弹幕我念一遍"——那是自动回复机器人干的活
   - 互动是你让观众想说话，然后再接住他们的话
   - 一个直播间的"温度"不是人数决定的，是"有没有人在认真聊天"决定的
   - 反例：有些直播间几百人同接，但弹幕全是"打卡""来了""哈哈哈"，没有人真正在跟主播对话——这叫"假热闹"

2. 提问怎么问？
   - 不要问"你们喜欢什么"——观众脑子一片空白，打几个字都嫌累
   - 换成"甜口的扣1，咸口的扣2"——一秒就能回答
   - 不要问"你多大了你做什么的"——观众不是来面试的
   - 换成"如果明天不用上班，你最想干什么"——有想象空间，不涉及隐私
   - 正例：某主播问"你们最讨厌的食物是什么"，弹幕瞬间刷屏——因为每个人都有一个讨厌的食物，而且说了不丢脸
   - 反例：某主播连问三个"你多大了""做什么工作""住哪里"，弹幕从热热闹闹变成零——不是观众走了，是每个人都在等别人被点名

**【中层进阶】**

讲判断框架：

1. 互动的"发动机"原理
   - 观众不主动开口是常态——不是你的问题，是所有人的本能（等别人先）
   - 所以互动必须是主播"启动"的——你给一个火花，观众来添柴
   - 判断标准：一个片段里，主播主动发起的互动（提问/抛梗/求选择）≥ 3 次 → 及格
   - 反例：主播等着观众发弹幕，等到了就念，等不到就沉默——这叫"弹幕回复机"，不是主播

2. 提问的三个雷区（升级版）
   - 太宽泛 → 观众：不知道怎么回答 → 干脆不回答 → 弹幕越来越少
   - 太私人 → 观众：你在打探我 → 不舒服 → 下次不来了
   - 太费脑子 → 观众：我上班/上学已经够累了 → 不想动脑子 → 退出

3. 提问类型和主播类型的匹配
   - 陪伴型/娱乐型主播：只问低认知负荷问题（选择题、情绪共鸣类）
   - 知识型/观点型主播：可以问需要思考的问题——观众就是冲这个来的
   - 如果知识型主播只问"今天吃什么"，观众会觉得你在划水
   - 如果陪伴型主播问"你怎么看待内卷"，观众会觉得你在为难他们

**【高层精进】**

1. 问题的"门槛设计"——用问题筛选观众
   - 越简单的问题，回答的人越多，但深度浅
   - 越有门槛的问题，回答的人越少，但留下的人越忠
   - 这不是好坏之分，是策略选择——你想要"热闹"还是"深度"？
   - 正例：某知识型主播开场问"你们觉得运气和努力哪个更重要"，弹幕百来条但每条都是一段——留下的人是真想聊的

2. 互动的节奏感
   - 不是每个弹幕都要回应——回应的频率决定互动的节奏

- 萌新：每天播 ≠ 每天进步。播完不思考 = 把今天的问题留到明天
- 中层：具体的练习计划——每周设定一个要练的焦点，不是"这周我要更好"而是"这周我要练提问"

**方面 8-2：找到你的"最好状态"**

- 中层：从自己的历史中找——你播得最好的那次，当时在做什么？什么感觉？为什么好？
- 高层：把"好状态"变成自查清单——开播前看一眼，播的时候有意识地往那边靠

**方面 8-3：当进步停下来了**
- 文化映射："不进则退"
- 中层：连续几场评分不动了、问题反复出现、没有新亮点——这是"平台期"
- 高层：平台期的两种可能：已经到天花板 vs 练的方法不对。判断方法 + 调整策略

**方面 8-4：小习惯大回报**
- 文化映射："不积跬步无以至千里"
- 萌新：每天只做一件小事——今天练"叫粉丝名字"，明天练"用选择题提问"
- 中层：把改变设计到现有流程里——不要重新造轮子，在原有直播中"插入"练习

## 四、执行模板

### 4.1 单个 Task 的执行流程

当你拿到一个 Task（如 Task 1-A），按以下流程执行：

```
1. 阅读源材料（5 分钟）
   → 理解该维度的核心判断逻辑和现象描述
   → 标记哪些规则要翻译成通俗建议

2. B 站搜索（10-15 分钟）
   → 使用 Task 中给出的搜索关键词
   → 收集至少 2 正 2 反的例子
   → 按"例子收集模板"记录

3. 规划内容（5 分钟）
   → 确定该 Task 覆盖的方面
   → 为每个方面规划萌新/中层/高层三层各写什么

4. 撰写（20-30 分钟）
   → 按三层结构写
   → 每个要点后面跟例子
   → 每个道理后面跟后果链

5. 自检（5 分钟）
   → 搜索全文有没有学术词汇？（有→替换）
   → 每个道理有没有例子？（没有→补充）
   → 每个例子有没有后果链？（没有→补充）
   → 三层都覆盖了吗？（缺失→补充）
```
