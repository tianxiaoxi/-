## 四、影响面计算与单焦点推荐（Step 3.5 收尾）

> 根因可以有多个。按影响面排序。教练只推一个焦点。

```mermaid
flowchart TD
    subgraph 根因[" 本场所有根因 "]
        R1["状态 ↓\n（链1根节点）\n影响面: 3"]
        R2["内容质量 ↓\n（独立问题）\n影响面: 1"]
    end

    R1 & R2 --> SORT["📊 按影响面从大到小排序"]

    SORT --> TOP["1. 状态 [影响面 3] ← 本期焦点\n2. 内容质量 [影响面 1] ← 下次关注"]

    TOP --> PICK["🎯 单焦点推荐：\n改状态。互动和营收自然会回升。"]

    TOP -.-> HIDE["📎 其余根因 → 折叠到扩展阅读\n标注'如果状态恢复后\n内容质量仍偏低，下周关注'"]

    style PICK fill:#4a4,stroke:#333,color:#fff
    style TOP fill:#ff9,stroke:#333
    style HIDE fill:#eee,stroke:#999
```

## 五、教练输出三层递进

```mermaid
flowchart TD
    subgraph L1[" Layer 1: 锚点（点状纠错）"]
        A1["'今天直播第三段，弹幕突然少了——\n你当时有感觉吗？'"]
    end

    subgraph L2[" Layer 2: 模式（归因到链条）"]
        A2["'你每次聊完复杂话题后都有2-3分钟断档——\n这是大脑在切换频道，不是你没话聊。'"]
    end

    subgraph L3[" Layer 3: 焦点（归因到根）"]
        A3["'你这周练一件事：感觉到累的第一个\n信号出现时，给自己30秒停顿。\n改状态，互动和营收自然会回升。'"]
    end

    L1 -->|"因果链存在"| L2 -->|"影响面已知"| L3

    L1 -.->|"无可辨识的模式\n停在这里"| STOP["停止：不做过度归因"]

    style L1 fill:#cdf,stroke:#333
    style L2 fill:#afd,stroke:#333
    style L3 fill:#4a4,stroke:#333,color:#fff

```
