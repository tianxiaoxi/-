## 016

**User:**

那程序成了什么样子，说下结构把

**AI:**

```python
import numpy as np

def cosine_sim(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-8)


class Character:
    def __init__(self):
        self.pool = 0.5
        self.memories = []

    def tick(self, event_emb, intensity, base_drain=0.05, base_recovery=0.02):
        drain = base_drain
        matched = []

        for m in self.memories:
            sim = cosine_sim(event_emb, m["emb"])
            threshold = 0.6 - m["intensity"] * 0.4
            if sim > threshold:
                drain += m["intensity"] * sim * 0.4
                matched.append(m)

        for i in range(len(matched)):
            for j in range(i + 1, len(matched)):
                drain += cosine_sim(matched[i]["emb"], matched[j]["emb"]) * 0.1

        self.pool = max(0, min(1, self.pool - drain + base_recovery))

        if intensity > 0.5:
            self.memories.append({"emb": event_emb, "intensity": intensity})

        return self.pool
```

34 行。一个 `pool`，一个 `memories`，一个 `tick`。三层：比对 → 结算 → 记忆。

复杂度从哪来？不是程序复杂——是 `memories` 长到几百条之后，事件匹配十几条记忆时的叠加效应。但程序本身不为那个复杂度买单。
