## 一、全部代码

```python
import numpy as np

def cosine_sim(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-8)


class Character:
    def __init__(self):
        self.pool = 0.5
        self.memories = []

    def tick(self, event_emb, intensity, base_drain=0.05, base_recovery=0.02):
        drain = base_drain
        matched = []

        for m in self.memories:
            sim = cosine_sim(event_emb, m["emb"])
            threshold = 0.6 - m["intensity"] * 0.4
            if sim > threshold:
                drain += m["intensity"] * sim * 0.4
                matched.append(m)

        for i in range(len(matched)):
            for j in range(i + 1, len(matched)):
                drain += cosine_sim(matched[i]["emb"], matched[j]["emb"]) * 0.1

        self.pool = max(0, min(1, self.pool - drain + base_recovery))

        if intensity > 0.5:
            self.memories.append({"emb": event_emb, "intensity": intensity})

        return self.pool
```

## 二、结构

```
数据：
  self.pool          — 一个 [0,1] 的数字
  self.memories     — 一个列表，每条存 embedding + intensity

每轮：
  ① 遍历记忆 → 当前事件的 embedding 与每条记忆做余弦相似度
    强度越高的记忆，激活阈值越低
    → 超过阈值的记忆被激活
    
  ② 激活的记忆之间做交叉传播
    → 相似的记忆互相放大消耗
    
  ③ COR 结算
    pool = pool - drain + recovery
    
  ④ 如果事件强度超过记录阈值 → 存入记忆

创建：
  方式一：预填一段 memories（经历逆推）
  方式二：memories 为空（从零开始）
```

## 四、代码里实际跑的东西

**一是记忆**。角色是被过去的特定时刻定义的。同一个事件，对不同记忆的角色，是不同的事件。

**二是相似度**。事件之间不需要被分类到某个域。相似的事件自然互相激活，不相似的自然不会。

**三是传播**。激活的记忆之间有交叉影响。这自动模拟了跨域传导——不是靠预设规则，是靠经历之间的相似度网络。

**四是阈值**。创伤越深，越容易被触发。一个 intensity=0.9 的创伤，sim>0.24 就激活。一个 intensity=0.5 的普通经历，sim>0.4 才激活。

**五是记忆**。强度超过 0.5 的事件被记录。这就是从零开始的创建路径——每一次高强度事件都在塑造角色。
