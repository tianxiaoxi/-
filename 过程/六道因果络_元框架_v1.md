## 〇、框架是什么，不是什么

### 0.1 定位

六道因果络不是一个"大统一理论"（grand theory），不声称对所有社会现象给出最终答案。它是一个**通用元框架（meta-framework）**——提供将任何社会现象拆解为可操作因果路径的分析方法。

三个核心元素来自社会系统存在的必要条件：

- **内部动力**：任何能"行动"的东西都有内部状态——资源、消耗、压力、信念
- **外部关系**：行动者在某个社会场域中与外部世界交换符号、资源、关系
- **边界机制**：内部动力和外部关系之间的渗透性决定了什么可被观测、什么被隔离

这三个元素不是被挑选出来的——它们是**社会系统存在的必要条件**。只要有一个能行动的东西，并且它在跟别的行动者打交道，就必然有内部动力、外部关系、以及两者之间的边界机制。六道因果络的贡献不是"发现了"这三个元素，而是**将它们从哲学描述变成了可操作的因果网络**。

### 0.2 与其他社会系统理论的区分

| 理论 | 共同失败原因 | 六道因果络做了什么不同的 |
|:---|:---|:---|
| **Parsons AGIL**（1951） | 四个功能是"假设的必然性"，无法验证 | 18 条路径各有 Step 3.5 检测规则 |
| **Luhmann 系统论**（1984） | "沟通系统"无法落为可检测数据 | 每个子系统有明确的数据检测信号 |
| **Coleman 微观-宏观桥接**（1990） | 只覆盖理性选择，情感/身份全丢 | JD-R 覆盖情绪、认知、生理、身份四线 |
| **Bourdieu 场域理论**（1992） | 说了"有场域、有资本、有惯习"但没说怎么动 | 每条路径有方向箭头和验证时序 |

共同失败原因：要么太抽象（无法操作化），要么只覆盖社会系统的一个层面（理性/权力/沟通），要么两者兼有。

### 0.3 框架对中程理论的组织方式

六道因果络不排斥任何中程理论。它的原创性在于：

1. **把不同的中程理论放进同一个因果网络**，定义了它们之间的交互规则——JD-R 的 burnout 输出如何在边界约束下进入 Goffman 的前台崩塌；Collins 的互动仪式如何与 Bandura 的自我效能形成正向反馈螺旋
2. **揭示了这些理论覆盖的路径并非独立运行**——它们通过交互面和 COR 资源池相互影响
3. **将自建的假说锚定到已有理论**——确保框架不依赖任何未被验证的假设

类比进化论：进化论不告诉你"这个物种具体长什么样"，但告诉你"为什么这个物种长成这样"。六道因果络不告诉你"这个行动者具体会怎样"，但告诉你"这个行动者在因果网结构中的动力学会走向哪里"。

### 0.4 框架的检验标准

1. **可操作化** —— Step 3.5 检测规则、自评量表、TR0-TR6 时间分片
2. **可证伪** —— 有明确的证伪条件
3. **多层面覆盖** —— 微观（个人状态）+ 中观（互动关系）+ 宏观（群体/社群/体系）
4. **跨域迁移性** —— 结构同构性在多领域被验证

## 一、双子系统 + 交互面

### 1.1 为什么需要两个子系统

当一个行动者在社会场域中自我呈现并与外部互动时，有两类本质不同的过程在同时发生：

- **内部状态变化**：消耗、缓冲、反馈、崩解——属于组织与健康心理学领域
- **外部互动逻辑**：呈现、关系建立、交换、内容共创——属于表演社会学、传播学、社会交换理论

前者在心理学中有成熟的理论骨架：**JD-R（Job Demands-Resources）Model**（Bakker & Demerouti, 2007）。后者涉及完全不同的学科领域——JD-R 完全不覆盖。

把两类路径强行编入同一个网会导致：(1) JD-R 已解释的关系被用多条理论重新推导，做了多余工作；(2) 两个子系统各自的逻辑被交叉混淆，难以看清各自独立运行的机制。

### 1.2 子系统一：行动者内部状态（JD-R 骨架）

JD-R 是一个经数千项实证研究验证的组织心理学框架，描述了任何"工作角色"中 demands（消耗）和 resources（缓冲/反馈）如何通过**COR 资源保存理论（Hobfoll）**竞争同一资源池，最终输出 burnout（耗竭）或 engagement（投入）。

在本框架中，行动者内部状态的 JD-R 映射如下：

**Demands（四线消耗）：**

| 路径 | JD-R 分类 | 消耗描述 | 学科锚点 |
|------|----------|---------|---------|
| ⑤ 表面呈现 | Emotional Demands | 外部表现与内部感受不一致产生的情绪劳动 | Hochschild 情绪劳动理论 |
| ⑦ 认知负荷 | Cognitive Demands | 内容准备、话题切换、信息处理的认知资源消耗 | Sweller 认知负荷理论 |
| ⑦' 生理基线 | Physical Demands | 行为活动本身的生理代价——时长、身体负荷、节律偏移 | Allostatic Load（McEwen & Stellar）适应负荷理论 |
| ⑨ 前台维护 | Psychological Demands | 维持前台形象所需的持续心理成本——表演纪律、印象管理、风险预防 | Goffman 前台维护成本 |

四条 demands 路径竞争同一资源池。当多条路径同时高企时，COR loss spiral 启动：生理资源损失 → 情绪调节资源减少 → 消耗加速 → 系统崩溃更早到来。

**Resources（缓冲/反馈）：**

| 路径 | JD-R 分类 | 缓冲描述 | 学科锚点 |
|------|----------|---------|---------|
| ⑤' 社会支持 | Social Support | 外部关系中的成员提供的情感缓冲——改变对压力事件的认知评估 | Cohen & Wills (1985) 社会支持缓冲假说 |
| ⑥' 绩效反馈 | Performance Feedback | 表现成果的反馈影响自我判断和后续状态 | Bandura 自我效能理论 |

**Burnout 输出：⑥ 前台崩塌**

JD-R 预测"持续高 demands + 低 resources → burnout"。但 JD-R **不预测 burnout 是否可被外部观测**——这取决于边界渗透性。

### 1.3 交互面：边界渗透性

交互面是子系统一（内部状态）和子系统二（外部社交）之间的界面。其核心变量是**边界渗透性**——决定了内部消耗是否在外部世界可见，以及外部力量是否渗透进内部状态。

四条交互面路径：

| 路径 | 方向 | 描述 |
|------|------|------|
| 心之壁 | 约束 | 边界渗透性决定⑥（前台崩塌）的可观测性 + ⑨（前台维护成本）的动态轨迹 |
| ⑧ 外部塑形 | 外部→内部 | 外部关系的期望和规范反过来塑造行动者的前台行为 |
| ①↺' 自我认知交互 | 双向 | 长期呈现行为渗透进自我认知（内化路径A）或保持为表达工具（工具路径B） |
| ERF 外部冲击 | 外部→内部 | 绕过正常社交渠道的外部事件直接冲击内部状态 |

交互面的学科锚点是 **Snyder 自我监控理论（Self-Monitoring Theory）**：个体根据外部情境调整自我呈现的程度。高自我监控 = 边界渗透性低（内部状态被隔离，外部不可见）；低自我监控 = 边界渗透性高（内部状态自然外露）。

### 1.4 子系统二：行动者-外部社交系统

覆盖行动者在其社会场域中的呈现、互动、关系建立、交换、内容生产与共创。

**核心动力：Collins 互动仪式链（Interaction Ritual Chains）**

互动仪式成功的四个要素：群体共在、边界对局外人、相互关注焦点、共享情绪。仪式成功 → 产生情绪能量（EE）、群体团结、共享符号、道德感。这是社交系统所有经过互动路径的底层动力。

**经过互动的路径（四条）：**

| 路径 | 方向 | 学科锚点 |
|------|------|---------|
| ① | 前台⇄互动（双向） | Goffman 拟剧论（前台→互动）+ Collins IRC（互动→前台固化） |
| ② | 互动→外部关系 | Horton & Wohl 准社会交往 + Collins IRC（仪式成功→情绪能量→关系积累） |
| ③ | 互动≈内容质量 | Ong 口语文化理论（在即时口头文化中，内容未被互动消费 ≈ 未发生） |
| ④ | 互动→资源流（交易） | Thibaut & Kelley 社会交换理论（感知收益 vs 比较水平） |

**非互动枢纽路径（五条）：**

| 路径 | 方向 | 学科锚点 |
|------|------|---------|
| ②' | 外部关系→资源流（关系型互惠） | 关系型互惠（guanxi 理论）——长期关系积累驱动资源交换 |
| ⑩ | 前台→内容（叙事同一性约束） | Burgoon 期望违背理论——偏离期望的前台内容被拒绝 |
| ⑪ | 内容→外部关系（内容驱动的归属） | 使用与满足理论（McQuail）——内容价值满足需求后形成关系 |
| ⑫ | 外部关系→内容（群体共创） | Jenkins 参与式文化理论——外部成员从消费者变为产消者 |
| ⑬ | 资源流→内容（资源投入） | 社会交换理论中"资源→投入"概念 |

## 二、18条因果路径（通用描述）

### 2.1 经过交互面的路径（子系统一 + 交互面）

#### ⑤ 呈现方式 → 内部状态

**方向**：呈现方式 → 内部状态（单场可检测）  
**子系统**：子系统一  
**学科锚点**：JD-R Emotional Demands + Hochschild 情绪劳动理论 + COR 资源保存

核心逻辑：不是"活动本身消耗体力"（体力账），而是"你呈现时用的身份和内部真实感受之间的距离，决定了消耗速度"。距离为零（自然流露）→ 消耗最小；距离很大（强撑、改变表达方式）→ 快速消耗。表面呈现（surface acting）改变外部表现而内心感受不变，消耗最高。情绪失调（emotional dissonance）——内外长期不一致——是持续消耗的根源。

与 COR 的关联：当表面呈现消耗 + 生理基线同时高企时，COR loss spiral 启动——生理资源损失 → 情绪调节资源减少 → 消耗加速 → 崩溃更早到来。

---

#### ⑦ 内容质量 → 内部状态

**方向**：内容质量 → 内部状态（单场可检测）  
**子系统**：子系统一  
**学科锚点**：JD-R Cognitive Demands + Sweller 认知负荷 + COR 资源保存

核心逻辑：内容准备和话题切换消耗认知资源。和表面呈现消耗的是同一个资源池（COR）。认知负荷高 → 可用于情绪控制的资源减少 → 内部状态下滑。

与 ⑤ 的区别：⑤ 的消耗源是内部-外部自我不一致（人格偏差），⑦ 的消耗源是认知层面的信息处理和创造力枯竭。两者叠加时消耗加速（COR loss spiral）。

---

#### ⑦' 行为活动 → 内部状态

**方向**：行为活动 → 内部状态（方向固定，幅度依赖长期对比）  
**子系统**：子系统一  
**学科锚点**：JD-R Physical Demands + Allostatic Load（McEwen & Stellar）+ COR 资源保存

核心逻辑：不管外部交流好不好——连续坐姿数小时、连续输出数小时、注意力持续集中数小时——这些是行为活动本身的生理代价。不是"体力耗尽"，是身体为了维持姿势、表达、注意力而持续进行生理调整，每一分钟都在产生适应负荷（allostatic load）。超过恢复阈值后，适应负荷累积到临界点。

与 ⑤/⑦/⑨ 的关系——COR 统一框架：四条 demands 竞争同一资源池。跨层叠加（生理+心理）时 loss spiral 更剧烈。

---

#### ⑨ 前台设定 → 内部状态

**方向**：前台设定 → 内部状态（长期隐藏成本，需长期对比）  
**子系统**：子系统一  
**学科锚点**：JD-R Psychological Demands + Goffman 前台维护

核心逻辑：设定并维持一个前台形象本身就是持续的心理成本——不是"表现得不一样"的瞬间消耗（⑤），而是"维持这个形象能成立"的持续固定成本。前台越复杂、离内部真实自我越远 → 维护成本越高。动态轨迹受边界渗透性影响：边界渗透性高 + 自我认知交互发生后 → 维护成本随时间下降（内部-外部距离缩小）；边界渗透性低 → 维护成本恒定或上升（持续隔离消耗）。

---

#### ⑤' 外部关系 → 内部状态

**方向**：外部关系 → 内部状态（单场可检测，需与 ⑤ 方向辨析）  
**子系统**：子系统一  
**学科锚点**：JD-R Social Support Resource + Cohen & Wills (1985) 社会支持缓冲假说

核心逻辑：外部关系中的成员提供的支持不改变消耗源本身，但改变行动者对消耗事件的认知评估（"不是那么糟"）→ 降低压力反应。这是 JD-R 中 Social Support 的核心缓冲机制。缓冲效率受边界渗透性影响：渗透性高 → 容易被支持到达内部；渗透性低 → 情感连接被隔离，支持难以穿透。

---

#### ⑥' 资源流 ⇄ 内部状态

**方向**：双向反馈（单场可检测）  
**子系统**：子系统一  
**学科锚点**：JD-R Performance Feedback Resource + Bandura 自我效能理论

核心逻辑：表现成果的反馈影响自我判断。正向——成果多 → "我能做好" → 自我效能上升 → 内部状态上升；负向——成果少 → 自我效能下降 → 内部状态下降。

正向螺旋：资源流入↑ → 自我效能↑ → 状态↑ → 呈现质量↑ → 资源流入进一步↑  
负向螺旋：资源流入↓ → 自我效能↓ → 状态↓ → 呈现质量↓ → 资源流入进一步↓

---

#### ⑥ 内部状态 → 前台崩塌（受交互面约束）

**方向**：内部状态 → 前台崩塌（可检测性受边界渗透性约束）  
**子系统**：子系统一 → 交互面  
**学科锚点**：Goffman 表演纪律崩解 + JD-R burnout 输出 + Snyder 自我监控约束

核心逻辑：当内部状态持续消耗，维持前台的表演纪律崩解，内部自我直接从裂缝中泄露。这是 JD-R 的 burnout 输出——但关键约束是：**可观测性由边界渗透性决定**。

- 边界渗透性高（低自我监控）→ 消耗累积 → 后台泄露 → ⑥ 可检测
- 边界渗透性低（高自我监控）→ 消耗持续累积 → 前台不崩 → ⑥ 沉默

沉默的 ⑥ 是更危险的情况：前台没有崩塌信号 → 分析系统可能判断"形象稳定"→ 但这是假象。内部消耗无出口 → 突然性崩溃风险更高。

### 2.2 经过交互面的路径（交互面）

#### 心之壁（边界渗透性）——约束所有交互面路径

**定位**：交互面核心变量  
**学科锚点**：Snyder 自我监控理论（Self-Monitoring Theory）

核心逻辑：行动者的内部状态在多大程度上可被外部世界观测到，取决于边界渗透性——即行动者根据外部情境调整自我呈现的程度。

| | 边界渗透性高（低自我监控） | 边界渗透性低（高自我监控） |
|:---|:---|:---|
| **Snyder 定义** | 行为反映真实态度和情绪状态 | 根据情境信号精确调整呈现 |
| **呈现类型** | 深度呈现 → 自然流露 | 持续表面呈现（工具化） |
| **前台稳定性** | 波动 → 内部会泄露 | 极其稳定 → 从不崩 |
| **⑥ 可检测性** | 可检测 | **沉默——最危险** |
| **⑨ 长期轨迹** | 随时间↓（自洽性增强） | 恒高或↑（持续隔离消耗） |
| **⑤' 缓冲效率** | 高（容易被支持到达内部） | 低（隔离了情感连接） |

为什么渗透性低时 ⑥ "看不出来"：(1) Goffman 高表演纪律——不是"演不好"，是"演得太好了"；(2) Hochschild 情绪失调的隐蔽性——外在表现一样的微笑，内部体验完全不同；(3) 系统假阳性风险——分析系统检测到"形象稳定"可能误判为健康信号，实际上这是持续消耗的代价。

**特殊检测规则**：

当以下条件同时满足时，触发边界渗透性低警报：

- ⑤（表面呈现消耗）持续偏高
- ⑦'（生理基线消耗）持续偏高
- ⑥（前台崩塌）持续沉默（连续多个时间单位以上）

系统不应将 ⑥ 沉默解读为"形象健康"，而应解读为"COR loss spiral 可能存在但不可通过前台数据检测"——推送后台自评量表。

---

#### ⑧ 外部关系 → 前台塑形

**方向**：外部关系 → 前台（长期缓慢，仅长期可检测）  
**子系统**：交互面（子系统二 → 子系统一）  
**学科锚点**：Snyder 自我监控 + 群体动力学（Lewin）

核心逻辑：当外部关系成员的成分发生变化（例如从某类群体变成另一类群体），行动者的呈现方式会在外部期望的推拉中慢慢偏移——不是在主动决定"我要改变"，是外部环境的要求在塑形前台行为。

与 ①↺' 的关系：⑧ 改变前台行为（外部推力），①↺' 是前台行为长期对内部的渗透（内部自动力）。如果外部推力持续 + 边界渗透性高 → 自我认知交互可能加速。

---

#### ①↺' 长期呈现 → 自我认知交互

**方向**：双向（极慢变量，以年为单位）  
**子系统**：交互面  
**学科锚点**：Bem 自我知觉理论 + Stryker 身份显著性（路径A）；Goffman 角色距离（路径B）

核心逻辑：长期重复某种呈现方式之后，行动者自身的自我知觉也在偏移。不是在"扮演"一个角色——是在长期观察自己行为之后，开始真的相信自己就是那样的人。

两条子路径：

- **路径A（内化）**：Bem 自我知觉适用——前台行为渗透内部，角色与自我逐渐融合。边界渗透性高时更容易发生。呈现者逐渐"变成"角色，内部-外部边界模糊。
- **路径B（工具）**：Goffman 角色距离适用——呈现者始终清楚"我在用一个角色表达自己"。内部获得安全表达通道，角色被感知为表达工具而非新身份。内部-外部边界保持清晰。

分界条件：元认知水平（个体差异变量）。低元认知 → 路径A；高元认知 → 路径B。同一行动者可能在不同阶段切换路径。

与 ⑧/⑨ 的关系：⑧ 是外部推力，①↺' 是内部自动力。如果内部正在向前台偏移（渗透性高）→ ⑨ 的固定成本随时间下降（越来越不需要"演"）；如果内部保持原样（渗透性低）→ ⑨ 的固定成本恒定。

---

#### ERF 外部冲击

**定位**：交互面（绕过正常社交渠道的外生冲击）  
**学科锚点**：Lazarus 威胁评估扩展 + 集体创伤理论

核心逻辑：某些事件不经过正常的社交互动通道，直接冲击内部状态。这些事件可能是个人层面的（健康危机、重大变故），也可能是群体层面的（社会事件、集体创伤）。入口映射：(1) →⑥ 直接触发前台崩塌；(2) →⑧ 改变外部关系对前台的塑形方向；(3) →⑥' 打断资源流-状态的正向螺旋；(4) →⑤' 使社会支持缓冲失效（当外部关系成员自身也受到冲击时）。

---

### 2.3 子系统二的路径（社交系统）

#### ① 前台 ⇄ 互动（双向）

**方向**：双向——前台→互动（快，单场可检测）；互动→前台（慢，长期可检测）  
**子系统**：子系统二  
**学科锚点**：Goffman 拟剧论（前台→互动）+ Collins 互动仪式链（互动→前台固化）

核心逻辑：

- 前台→互动（快变量）：行动者选择的形象决定了互动风格——语气、回应方式、接话逻辑。前台纪律决定互动风格与前台的一致性。
- 互动→前台（慢变量）：外部对"你是什么样的人"的认知，不是听你自我介绍形成的，是观察你多次互动方式之后形成的。这是 Collins "仪式成功 → 神圣符号"的长期累积效应——互动仪式成功产生共享符号化认知。

---

#### ② 互动 → 外部关系

**方向**：互动 → 外部关系（单向，单场可检测）  
**子系统**：子系统二  
**学科锚点**：Horton & Wohl 准社会交往理论 + Collins 互动仪式链

核心逻辑：互动的方式决定了谁被吸引、谁留下、留下的人形成什么关系类型。准社会关系强度 = 外部成员感知到的"互动回应力"的累积。Collins 互动仪式成功 → 产生情绪能量（EE）→ 群体团结 → 外部成员留下。没有"关系好→互动自然好"的机制——关系是积累的，每次互动必须从头完成仪式。

---

#### ③ 互动 ≈ 内容质量

**方向**：高度相关，不恒等（约等于号，单场可检测）  
**子系统**：子系统二  
**学科锚点**：Ong 口语文化理论

核心逻辑：在即时口头文化环境中，内容没有被互动消费就等同于没发生。Ong 不会用"内容质量"来评价口语传播——他会用"是否有听者参与"。在即时场景中，听者参与的唯一指标：内容说出后是否被接收和响应。

约等于号的含义：在概念层面高度重叠，但在分析操作层面作为两个独立维度产出评分。如果互动评分 ≠ 内容评分，这本身就是重要发现——矛盾信号检测的优先检查项。

---

#### ④ 互动 → 资源流（交易型）

**方向**：互动 → 资源流（单向，单场可检测）  
**子系统**：子系统二  
**学科锚点**：Thibaut & Kelley 社会交换理论

核心逻辑：互动产生的价值分两路——情感部分流向外部关系（被记住、被认可），非情感部分流向资源交换（交换平衡、互惠）。资源流不是互动的目的，是互动中交换平衡之后的自然结果。比较水平（CL）——外部成员基于过往消费体验的期望值——互动好 → 感知收益 ≥ CL → 资源自然流入；互动差 → 感知收益 < CL → 资源不流入。

与 ②' 的区别：④ 是交易型互惠（每次独立结算），②' 是关系型互惠（长期积累的"关系账户"产出）。

---

#### ②' 外部关系 → 资源流（关系型互惠）

**方向**：外部关系 → 资源流（单向，单场可检测）  
**子系统**：子系统二  
**学科锚点**：关系型互惠（guanxi 理论）

核心逻辑：一个长期关系的成员提供资源，不是因为"今晚的互动好"——是因为长期关系让他们觉得"应该支持"。资源不是还今晚的交换账，是维护这段关系。矛盾信号——互动平平但资源流正常或偏高 → 关系型互惠在工作，这是正向信号。但需关注：如果长期依赖关系型互惠而交易型互惠持续低，说明新生互动的交换价值产出不足。

---

#### ⑩ 前台 → 内容

**方向**：前台 → 内容（单向，单场可检测）  
**子系统**：子系统二  
**学科锚点**：Burgoon 期望违背理论（Expectancy Violation Theory）

核心逻辑：前台的设定决定了能产出什么类型的内容。基于前台形成的内容期望——内容偏离期望 → 期望违背 → 外部成员的认知成本高 → 内容被拒绝。McAdams 叙事身份理论补充：一致性是好叙事的基础，前台提供了叙事框架——框架内的内容被接受，框架外的被排斥。

---

#### ⑪ 内容 → 外部关系

**方向**：内容 → 外部关系（单向，单场可检测）  
**子系统**：子系统二  
**学科锚点**：使用与满足理论（Uses and Gratifications, McQuail）

核心逻辑：外部成员选择关注一个行动者的动机可以是多维的——有人为了互动，有人为了内容本身。内容价值 → 功能性需求被满足 → 变成习惯消费 → 关系在内容消费中慢慢建立。

与 ② 的区别：②（互动→外部关系）是关系驱动——"我被你看见了所以我留下"；⑪（内容→外部关系）是内容驱动——"你提供的东西有价值所以我留下"。

---

#### ⑫ 外部关系 → 内容质量（群体共创）

**方向**：外部关系 → 内容质量（单向，长期累积显现）  
**子系统**：子系统二  
**学科锚点**：Jenkins 参与式文化理论（Participatory Culture）

核心逻辑：外部成员的参与不只是对行动者的回应——参与本身就是内容的一部分。当外部关系好，成员会在互动中提供话题、展开创意、互相接力。这些参与是内容生产的原材料。Jenkins 框架下的三个层次：

- L1（传播/参与）：成员提供内容原材料——任何人都能做
- L2（共创）：成员之间互相展开创意、创造新元素——需要一定凝聚力
- L3（集体智慧）：群体独立产出内容文化，行动者只是参与其中——需要强群体文化+高创意密度

---

#### ⑬ 资源流 → 内容质量

**方向**：资源流 → 内容质量（单向，间接，长期可见）  
**子系统**：子系统二  
**学科锚点**：社会交换理论中"资源→投入"概念

核心逻辑：资源流入影响行动者能投入多少在内容上——更多时间准备、更好的产出工具、更精细的筹划。交换产出 → 资源积累 → 可用于下一轮交换的投入增加。

---

## 三、边界渗透性

### 3.1 角色与定义

边界渗透性是子系统一（内部状态）与子系统二（外部社交）之间的**核心界面变量**。它决定了两件事：

1. **内部状态是否可被外部世界观测到**——即 ⑥（前台崩塌）的可检测性
2. **外部力量是否渗透进内部状态**——即 ⑤'（社会支持）的缓冲效率、⑧（外部塑形）的穿透深度

边界渗透性的学科锚点是 **Snyder 自我监控理论**：个体根据外部情境调整自我呈现的程度。高自我监控 = 低渗透性（隔离），低自我监控 = 高渗透性（通透）。

### 3.2 渗透性高/低对路径的影响

| 影响路径 | 渗透性高 | 渗透性低 |
|:---|:---|:---|
| ⑥ 可检测性 | 可检测——内部消耗 → 前台崩塌可见 | 沉默——外部看来总是正常，最危险 |
| ⑨ 长期轨迹 | 消耗随时间↓（内部-外部距离缩小，自洽性增强） | 消耗恒高或↑（持续隔离成本） |
| ⑤' 缓冲效率 | 高——容易被外部支持到达内部 | 低——情感连接被隔离 |
| ①↺' 方向 | 内化路径A或工具路径B均可能 | 路径A不发生（内部被保护）；路径B可能仍成立 |

### 3.3 低渗透性（高自我监控）的特殊检测规则

低渗透性下 ⑥ 持续沉默是最危险的假象。系统必须配置警报机制：

```
检测模式：⑤持续偏高 + ⑦'持续偏高 + ⑥持续沉默（连续多个时间单位以上）
  触发动作：
  1. 标记为"低渗透性嫌疑"
  2. 推送后台状态自评量表
  3. 自评第三模块（Snyder自我监控）得分 ≥12 → 确认低渗透性路径
  4. 确认后：系统不再将⑥沉默解读为"形象健康"
     改为解读为"COR loss spiral可能存在但不可通过前台数据检测"
```

### 3.4 外部冲击（ERF）的入口映射

外部冲击是不经过正常社交互动通道、直接冲击内部状态的外生事件。四条入口路线：

| 入口 | 冲击路径 | 机制 |
|------|---------|------|
| →⑥ | 直接触发前台崩塌 | 绕过 JD-R 资源消耗过程，直接摧毁表演纪律 |
| →⑧ | 改变外部塑形方向 | 外部关系成员对呈现的期望发生根本性改变 |
| →⑥' | 打断资源流-状态正向螺旋 | 外部冲击 → 资源流断裂 → Bandura 正向螺旋中断 |
| →⑤' | 使社会支持缓冲失效 | 当提供支持的外部成员自身也受到冲击时，支持不可用 |

## 四、数据抓取协议

### 4.1 时间分片协议（TR0-TR6）

时间分片是数据抓取的基本单位——将连续的时间流切分为可操作的分析区间。TR 分片不是检测信号，是分片类型的通用定义。

| 分片 | 名称 | 通用定义 | 协议字段 | 数据类型 |
|------|------|---------|---------|---------|
| TR0 | 仪式峰判定 | 标记一个时间区间内互动仪式是否成功——是否产生了情绪能量、群体团结、共享符号 | `ritual_success`, `emotional_energy_delta`, `group_solidarity_signal` | bool, float, string |
| TR1 | 仪式-消耗时序 | 记录互动表现（表面呈现程度）与内部状态消耗的时间序列关系 | `surface_acting_level`, `state_trajectory`, `timing_gap_ms` | float[0-1], list[float], int |
| TR2 | 状态下滑斜率 | 测量内部状态在多个时间单位内的下降速率 | `state_values[], slope_coefficient, inflection_point` | list[float], float, int |
| TR3 | 空档期频率 | 记录社交场域中无互动时段的数量、长度、分布 | `gap_count`, `gap_durations[], gap_density` | int, list[int], float |
| TR4 | 资源流时序分布 | 记录资源交换事件的时间分布模式 | `exchange_events[]`, `distribution_pattern`, `clustering_index` | list[dict], string, float |
| TR5 | 边界渗透性 × 波动性交叉 | 交叉分析边界渗透性与内部状态波动性的关系 | `permeability_score`, `state_volatility`, `cross_correlation` | float, float, float |
| TR6 | 生理消耗基线 | 追踪行为活动本身的生理代价累积——时长、连续活跃天数、节律偏移 | `activity_duration_min`, `consecutive_days`, `circadian_offset`, `vocal_load_pct` | int, int, float, float |

每个分片的 `领域填写示例` 字段为占位符，由具体领域的 domain_knowledge 文件填充。例如 TR0 在某个领域的示例可能为 `[领域]仪式峰判定：[具体检测方式]`。

### 4.2 事件分类协议

外部世界发生的事件按五个方向分类，对应到六道因果络的分析维度：

| 方向 | 通用名称 | 描述 | domain_registry 字段 |
|------|---------|------|---------------------|
| **autonomy** | 自主方向 | 行动者被外部力量约束/控制/施压/挑战自主性的所有事件 | `five_domain_mapping.autonomy.events` |
| **social** | 社会方向 | 行动者被外部世界接纳/认可/冷落/拒绝/孤立的所有事件 | `five_domain_mapping.social.events` |
| **financial** | 资源方向 | 资源流入/流出/中断/结构变化的所有事件 | `five_domain_mapping.financial.events` |
| **cognitive** | 认知方向 | 创新/创作/知识产出/认知投资及其成败的所有事件 | `five_domain_mapping.cognitive.events` |
| **peer** | 同侪方向 | 与同级行动者的比较/竞争/排名/合作的所有事件 | `five_domain_mapping.peer.events` |
| **交互面** | 边界方向 | 直接作用于边界渗透性的事件——外部世界的信息穿透内部，或内部状态被迫外露 | 结合路径 ①↺'/⑧/ERF |

五个方向的事件通过交互面的映射规则影响子系统一的内部状态。`events` 字段定义"什么事件属于这个方向"，`indicators` 字段定义"用什么指标检测这个方向的状态"。两者需在领域知识文件中完成领域特化。

### 4.3 路径验证协议

#### 已知固定方向的路径

| 编号 | 方向 | JD-R 标注 | 验证方式 |
|------|------|---------|---------|
| ② | 互动→外部关系 | — | 互动变动时间 vs 外部关系变动时间的时序比较 |
| ③ | 互动≈内容质量 | — | 约等于号，二者评分高度相关即正常，脱钩即矛盾信号 |
| ④ | 互动→资源流(交易) | — | 互动的交换部分 → 资源流变动时序 |
| ⑤ | 呈现方式→状态 | Emotional Demands | 表面呈现信号时间 vs 状态信号时间的时序比较 |
| ⑦ | 内容质量→状态 | Cognitive Demands | 内容空档信号 → 状态信号时序 |
| ⑦' | 行为活动→状态 | Physical Demands | 时长/连续活跃天数/节律偏移 → 状态趋势（幅度依赖长期对比） |

#### 需要每场判断方向的路径

| 编号 | 可能方向 | 判断依据 |
|------|---------|---------|
| ① | 前台⇄互动（快/慢） | 前台偏移信号 vs 互动变味信号的时序 |
| ⑤ vs ⑤' | 呈现→状态 vs 社会支持→状态 | 状态信号与呈现信号的时序 vs 与外部关系信号的时序 |
| ⑥' | 资源流⇄状态（Bandura 正/负螺旋） | 资源流信号 vs 状态信号的时序方向 |
| ⑥ | 状态→前台（仅在可检测时） | 状态先于偏移 → 确认⑥；否则检查 ⑤/⑦/⑦'/⑨ 或触发渗透性检测 |

#### 单场可检测 vs 仅长期可检测

**单场可检测（13条）**：①②③④⑤⑥⑥'⑦⑦'⑩⑪②'⑤'（其中 ⑤/⑤'、⑥' 需判断方向；⑥ 受渗透性约束；⑦' 方向固定但幅度依赖长期）

**仅长期可检测（5条）**：①↺ ①↺' ⑧ ⑨ ⑫（慢变量/隐藏变量，变化单位为多个时间单位）

### 4.4 领域知识装载协议

#### domain_registry.yaml 字段规范

**必需字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `domains.<领域名>.domain_file` | string | 指向领域知识文件的相对路径 |
| `domains.<领域名>.description` | string | 领域的一句话描述 |
| `domains.<领域名>.five_domain_mapping` | object | 五方向的领域特化映射 |
| `five_domain_mapping.<方向>.events` | string | 该方向的事件类型描述 |
| `five_domain_mapping.<方向>.indicators` | string | 该方向的检测指标描述 |

**可选字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `domains.<领域名>.status` | string | 领域映射完成状态 |
| `domains.<领域名>.triggers_examples` | list[string] | 触发该领域分析的搜索关键词示例 |

#### domain_knowledge/*.md 必需章节

每个领域知识文件必须包含以下章节：

1. **领域六维度映射**：将六道因果络的六个方向 + 交互面翻译为该领域的特化语义
2. **搜索模板**：用于在线搜索该领域行动者公开信息的结构化查询模板
3. **学科映射**：该领域特定的学科补充——不修改框架结构，仅替换学科锚点的领域特化版本（如某个领域用防御性现实主义替代 Hochschild 情绪劳动）
4. **报告模板**：基于六维度分析结果的标准化输出格式

### 4.5 道一输入接口

六道因果络的分析输出通过以下映射规则传输给道一34行引擎：

**TR 分片数据 → 引擎 `memories` 列表**：

每个时间分片的关键事件转换为一条引擎记忆：

```python
{
    "emb": [event_embedding_vector],  # 事件的向量表示
    "intensity": 0.0-1.0               # 事件的影响强度
}
```

多分片汇总后形成引擎的初始 `memories` 列表。向量表示由领域知识中的事件特征编码规则产生。

**六维度综合评分 → 初始 `pool` 值**：

```
pool_initial = f(dim1, dim2, dim3, dim4, dim5, dim6)
```

映射公式将六个维度的评分综合为一个 [0,1] 区间的初始资源池值。具体权重由领域校准数据决定。

**路径激活状态 → 记忆间初始关系**：

被标记为"已激活"的因果路径对应的事件对，在引擎初始化时赋予较高的初始相似度权重，确保引擎在前几轮推演中优先处理这些已知的因果关联。

## 五、眼镜与世界

### 5.1 核心比喻

> 六道因果络是"眼镜"（分析框架），道一引擎是"世界"（生成引擎）。框架分析结构，引擎生成动态——**眼镜不需要进入世界**。

戴上六道因果络的眼镜看一个社会系统，你看到的是：这个行动者的内部状态在哪些路径上被消耗，外部关系在哪些维度的仪式链上累积或断裂，边界的渗透性让这些变化在多大程度上可见。框架输出的是结构化的分析报告——路径状态、分片数据、风险点、解决方案。

道一引擎拿到的则是另一个东西：一段初始记忆列表和一个资源池数字。引擎不知道"边界渗透性"是什么，不知道"JD-R 四线消耗"，不知道"Collins 仪式链"。它只知道：记忆、相似度、扩散、结算——34 行代码。

框架定义"看什么"和"怎么看"，引擎在这个分析的基础上推演"之后会发生什么"。两者的分离是干净的：框架的语言不会进入引擎，引擎的推演逻辑不会被框架的术语污染。

### 5.2 命理推演为什么废弃

三生万物的早期版本试图用命理概念（五行生克、十二长生、格局、用神、刑冲合害、大运）作为参数映射系统来驱动角色模拟。这些概念在 v6-v7 的剥离过程中被逐一证明是总结语言，而非运行所需的变量：

| 废弃的概念 | 被废弃的原因 | 引擎中自然涌现的方式 |
|:---|:---|:---|
| 五行生克矩阵 | 域是不存在的——事件不被分类到某个域，分类是分析者的总结语言 | 引擎第②步（激活记忆之间的交叉传播）自动产生跨域传导——相似的事件自然互相激活，不需要生克规则 |
| 十二长生阶段名 | 阶段名是 pool 值区间的事后描述，不是驱动因素 | pool 浮动在 [0,1] 区间，阶段名是总结语言——不是"进入了某个阶段所以 pool 变了"，是"pool 变了之后被描述为某个阶段" |
| 格局 | 格局是 memories 列表的拓扑结构的事后描述 | memories 列表本身就是拓扑结构。事件的排序和关联关系定义了格局，不需要额外赋予"格局名" |
| 用神域 | 域不存在则用神不存在 | 引擎不需要知道"哪个方向恢复倍率更高"——相似度网络会自动找到最有效的恢复路径 |
| 刑冲合害 | 事件之间的冲突/和谐是 cosine_sim 阈值匹配的自然结果 | 引擎第①步的 similarity > threshold 判定：相似度高的事件互相激活（合），相似度低或对抗性的事件形成冲突模式（刑冲）——不需要预设冲突矩阵 |
| 大运周期 | 周期由记忆密度驱动，不是由时间驱动 | 密集的高强度记忆 → 激活阈值低 → 更多记忆被触发 → 消耗加速或恢复加速。周期是记忆密度的涌现属性 |

**推演不是先有命理规则再跑参数——推演是"给道一一段初始记忆，让它逐轮跑"。比任何参数映射方案更简洁、更强。**

### 5.3 道一的通用性

道一引擎不区分任何实体类型。它的输入只是：一段初始记忆（事件向量 + 强度）和一个资源池值。给道一一段关于某个行动者的初始 memories，它就能逐轮模拟这个行动者在压力事件序列下的内部状态演化——哪些记忆被激活、资源池何时跌破临界点、消耗的多米诺骨牌何时开始倒塌。

引擎不"知道"它模拟的是什么类型的行动者。它只知道：这段记忆和那段记忆有多相似，激活它们需要多少资源，传播会产生多大的连锁消耗。这是真正的通用性——不是通过参数映射把不同的东西映射到同一个框架，而是**引擎根本不需要知道它在模拟什么**。

> 眼镜帮你看清结构。世界帮你看见未来。
> 眼镜只负责看清楚。未来由世界自然涌现。
