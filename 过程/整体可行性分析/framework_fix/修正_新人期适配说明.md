> 修正类型: 新增章节
> 建议插入位置: 框架v2第二章"经过互动的路径"之前（约第95行，即在"一、完整关系图"之后）
> 修正理由: L1中"新人期真空"是最高频的"框架未覆盖"标记（5个案例），但这不是框架的理论缺陷——是数据可用性问题。需要给分析者明确的降级方案。

### 新人期（<3个月）的特殊处理 ⚠

六维框架假设主播有足够的活动数据积累（≥10场直播、≥3个月运营周期）。对于出道<3个月的新人：

#### 路径可检测性分级

| 路径 | 新人期可检测? | 原因 |
|------|:----------:|------|
| ① 人设⇄互动 | ⚠ 部分可检测 | 人设→互动方向可判断，但①↺方向（观众图式形成）不可检测 |
| ② 互动→粉丝 | ⚠ 早期信号 | 准社会关系建立需要数周-数月，早期信号不可靠 |
| ③ 互动≈内容 | ✓ 可检测 | 单场即可判断，新人期同样适用 |
| ④ 互动→营收 | ✗ 不足 | 营收循环通常在3-6个月后才形成 |
| ⑤ 互动→状态 | ⚠ 部分可检测 | 首月"蜜月期"新鲜感红利可能掩盖真实消耗斜率 |
| ⑦ 内容→状态 | ⚠ 部分可检测 | 新人常见"内容储备不足"→认知空档可预判 |
| ⑦' 直播行为→生理基线 | ⚠ 部分可检测 | 首月排班密度可预判但无法验证累积效应 |
| ⑨ 人设→状态 | ⚠ 间接推断 | 取决于人设与真实自我的距离（新人期通常不确定） |
| ⑩ 人设→内容 | ✓ 可检测 | 新人期最可靠的路径 |
| ①↺' | ✗ 不可检测 | 跨年极慢变量 |
| ②' 粉丝→营收 | ✗ 不足 | 关系型互惠需要时间积累 |
| ⑤' | ✗ 不足 | 社会支持需要粉丝基数 |
| ⑥ 状态→人设 | ✗ 不可检测 | 新人期尚未积累足够消耗 |
| ⑥' | ✗ 不足 | 营收循环未形成 |
| ⑧ 粉丝→人设 | ✗ 不可检测 | 跨场慢变量 |
| ⑪ 内容→粉丝 | ⚠ 早期信号 | 内容驱动的粉丝获取需要时间 |
| ⑫ 粉丝→内容 | ✗ 不可检测 | 群体共创需要充分的社群积累 |
| ⑬ 营收→内容 | ✗ 不可检测 | 资源循环未形成 |

**总结**: 新人期后17条路径中仅 **5条可检测**（③⑦⑩ + ①⑦'⑨的部分方向），其余必须标注为"数据不足·新人期"。

#### 评分降级规则

| 维度 | 新人期评分处理 |
|------|--------------|
| 人设定位 | 可评分（基于出道设定+初配信表现），标注"预判级·⚠" |
| 互动效果 | 可评分但可靠性低，标注"预判级·⚠" |
| 粉丝关系 | 评分标注"预判级·⚠·信息严重不足" |
| 流水营收 | 几乎必定为"信息不足"（YouTube未达收益化门槛/B站未达舰长门槛） |
| 个人状态 | 标注"N/A·新人期"（无历史对照无法判断是正常还是偏差） |
| 内容质量 | 可评分，标注"预判级·⚠" |

#### 新人期独有风险清单

这些风险在标准17路径中可能被遗漏或低估，需要单独提取：

**风险1: "蜜月期陷阱"** ⚠
出道1-3个月的新鲜感红利可能掩盖真实的⑤消耗斜率。

- 案例: BY THE BEAT（出道1年3个月，L1标注"VTuber倦怠通常出现在1.5-3年区间——可能处于蜜月期尾端"）
- 检测: 首月消耗信号≤"正常疲劳"，不应解读为"不会倦怠"

**风险2: ⑦'首月过密排班** ⚠
新人期为了快速积累内容/粉丝，常见排班密度过高。

- 案例: Zoyee（每日三场+深夜档23:18开播 → "定时炸弹"）
- 案例: すずねのなる（"每日配信+早晨时间带"极高频率承诺 → "1-3个月内显性化"）
- 检测: 单场>4小时+每日排班 → 标注"生理消耗基线不可持续·新人期过密"

**风险3: ⑨人设磨合期消耗** ⚠
新人的表演技巧尚未自动化（deep acting尚未形成），表面表演消耗可能在新人期达到峰值。

- 案例: 플라네타 데네브（出道日即达仪式能量耗竭峰值——"首次仪式即耗竭"）
- 检测: 新人期⑤消耗信号≥"强" → 标注"新人期⑨磨合成本叠加，非长期消耗基线"
