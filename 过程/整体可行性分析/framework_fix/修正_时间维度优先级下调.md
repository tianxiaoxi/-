### 节奏是六维网络的时域涌现属性

一场直播里，至少有6个内生驱动力影响节奏：

1. Collins互动仪式链的成功/断裂 → 峰/谷的形成
2. ⑤情绪劳动消耗斜率 → 状态下滑陡度
3. 心之壁薄/厚 → 低谷的外显/隐蔽程度
4. ⑦认知负荷空档 → 断点密度
5. ⑦'生理消耗基线 → >4小时场的不可逆下滑趋势
6. ⑥'营收⇄状态反馈 → 正向锁/负向锁的惯性方向
