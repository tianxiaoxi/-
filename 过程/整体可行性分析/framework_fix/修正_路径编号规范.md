#### 信号强度评级统一标准

| 评级 | 含义 | 触发条件 |
|:----:|------|---------|
| 强 | 检出 + 明确独立信号 | 路径方向确认，有≥2个独立可验证信号 |
| 中 | 检出 + 含混信号 | 路径方向可能成立，但信号来源单一或间接 |
| 弱 | 推断 | 无直接信号，基于其他维度的关系推断 |
| 沉默 | 应检出但未检出 | 前提条件满足但路径信号缺失（如⑥在心之壁厚时） |
| 不足 | 信息不足 | 无法判断是因为无信号还是信息不可得 |
| 不适用 | N/A | 路径概念上不适用于此案例（如AI主播的⑤/⑥/⑦/⑨） |

#### 为什么需要这条规范

l0_stats.json 的 path_signals 暴露了路径命名混乱的严重程度：

- **①↺'** 单一路径有 **20+个不同命名变体**（含中/日/英三种语言+不同括注格式）
- 每个变体只有1-2个实例，导致路径检出率统计完全碎片化
- 同样的碎片化问题出现在②'、④、⑤、⑥等多条路径

**当前状态**: 路径统计不可用 → **修正后**: 路径可直接做跨案例检出率对比
