# v4→v5 订正：剥掉冗余层

> 对 v4 的简化订正。
>
> 核心发现：**心之壁不是独立变量，是两边状态的间隙。格局、人格、触发表同理——都是推导值，不需要计算和存储。**
>
> 记录于 2026-06-28。

---

## 一、心之壁不需要算

### v4 的做法（冗余）

```
独立维护：
  heart_wall_1.thickness
  heart_wall_1.integrity
  heart_wall_1.baseline
  heart_wall_2.thickness
  heart_wall_2.integrity
  heart_wall_2.baseline
```

### 订正

心之壁不是东西，是**缝隙**。缝隙的宽度不由自身决定，由两边的状态差自然决定。

```
raw后台的 demand 堆积速度 vs 内部前台的意识接纳速度
  → 差距大 → 心之壁₁ 厚
  → 差距小 → 心之壁₁ 薄
  → raw后台 burst 冲破意识过滤 → 心之壁₁ 裂

内部前台的意识内容 vs 外部前台的表达内容
  → 差距大 → 心之壁₂ 厚
  → 差距小 → 心之壁₂ 薄
```

**不存。不计算。** 两边状态已知，间隙自然已知。`heart_wall.thickness`、`integrity`、`baseline` 全部是冗余变量。

---

## 二、格局不需要存

格局是各域敏感度之间的**拓扑关系**。关系不是东西。各域状态已知，拓扑自然已知——不需要「判定格局」这个步骤，更不需要存格局名称。

---

## 三、触发表不需要预设

### v4 的做法

每个符号上挂 `ritual_activation_triggers`——场景模式、情绪线索、角色位置、语言模式。

### 订正

```
当前事件 → 与所有已记录的高强度经历做相似度比对 → 超过阈值 → 激活

而不是：

当前事件 → 查预设触发表 → 匹配 → 激活
```

符号不是需要预设触发条件的东西——它本身的原始情境就是触发条件。相似度由当前刺激与原始场景在多个维度上的重合度自然产生。

**不存触发表。** 存经历本身即可，匹配是运行时自然发生的。

---

## 四、五大人格不存

这是 v1 就说过的——五大人格是长期运行后的行为聚类，是**输出的影子**，不是输入。

---

## 五、最简形态

剥掉所有冗余层后：

```
状态层（唯一需要存储的）：
  各域 energy_pool, demands, resources

经历层（唯一需要记录的）：
  过去的高强度事件
    - 当时的情境特征
    - 域归属
    - 情绪强度

每轮：
  外部事件 → 
  五域分类（事件落在哪个域）→
  与经历层做相似度比对 →
  匹配则激活 → 临时消耗/恢复 →
  COR 统一分配 →
  输出当前状态

全部。
```

六道因果络框架不改——它仍然是分析工具，告诉你「这个六维因果网的结构是什么、互动面在哪里」。

订正的是引擎层：不需要在心之壁、格局、触发表、人格这些中间产物上浪费变量。它们是**知识的总结，不是运行的零件**。

## 六、剥离清单

| 剥掉的 | 为什么 |
|--------|--------|
| 心之壁 thickness/baseline/integrity | 两边状态的间隙，不存 |
| 心之壁 crack_mode | raw后台冲破意识过滤时自然发生，不存状态名 |
| 格局判定/格局名称 | 拓扑关系，推导即可 |
| 触发表 (ritual_activation_triggers) | 经历本身即触发条件，相似度比对自然产生 |
| 五大人格映射器 | 输入输出同源，循环论证 |
| 用神域重新判定 | 各域恢复倍率已知时自然可知 |
| 十二长生阶段名 | energy_pool 已知时阶段自然已知 |
| domain_sensitivity（敏感度）| 由经历的累积消耗历史体现，不存独立分数 |
