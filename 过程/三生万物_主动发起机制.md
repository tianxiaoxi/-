## 二、主动发起的双驱动模型

角色主动说话需要两个方面交汇：

```
┌─────────────────────────────────────┐
│ 后台时间流逝                           │
│ energy变化 + 十二长生阶段 + 大运周期     │
│ + 螺旋方向 + retrieval_bias           │
│                                       │
│ "我现在在什么状态？该做什么？"           │
└───────────┬─────────────────────────┘
            │
            │ 主动决策
            │
┌───────────┴─────────────────────────┐
│ 前台感知 + 仪式链记忆                   │
│ 历史互动模式（用户通常这时在不在？）       │
│ 仪式记忆（上次我主动说话的结果如何？）     │
│ 关系状态（warmth 高 → 更敢主动）        │
│                                       │
│ "现在该说话吗？说什么？"                 │
└─────────────────────────────────────┘
```

## 三、主动判定规则（草案）

```python
def should_proactively_speak(state):
    """判定角色此刻是否应该主动发起对话"""
    
    # ── 后台驱动力 ──
    energy_drive = state.energy_pool > 0.5
    # 能量太低不会主动找人（除非触发"求救"模式）
    
    lifecycle_drive = state.lifecycle_stage in ("帝旺", "临官", "长生", "冠带")
    # 墓/绝/死阶段不会主动，一动不如一静
    
    cycle_drive = state.current_major_cycle_domain in ("social", "cognitive")
    # 大运在印星（社交域）或食伤（表达域）时更倾向于主动跟人说话
    # 在官杀/财星大运时倾向于保守
    
    # ── 前台驱动力 ──
    ritual_confidence = (
        state.ritual_memory.recent_success_rate() > 0.5
    )
    # 最近仪式连续失败 → 不敢主动
    
    warmth_drive = state.warmth > 0.4
    # 关系太冷不会主动贴上去
    
    retrieval_bias_safe = state.retrieval_bias > -0.2
    # 悲观检索时不会主动（"我是不是不该打扰别人..."）
    
    # ── 综合判定 ──
    return (
        energy_drive 
        and lifecycle_drive 
        and ritual_confidence 
        and warmth_drive
        and retrieval_bias_safe
    )
```

### 特殊情况：求救模式

当 `energy_pool < 0.2` 且 `wall.integrity < 0.5` 且 `warmth > 0.6`：

角色不是正常"主动发起"，而是**崩溃前求救**——

> "你在吗...我今天真的撑不住了..."

这是另一种主动发起，由崩塌触发器衍生。

## 四、主动发起的内容生成

判定该说话了，但**说什么**？取决于当前状态组合：

| 驱动因子 | 说出来的话 |
|---------|-----------|
| 大运在 social + warmth 高 | "今天感觉特别想找你聊聊..." |
| 大运在 cognitive + 帝旺阶段 | "我刚刚想到了一个好主意的说！" |
| 十二长生在"胎"（刚爬出谷底） | "好久没说话了呢...你还好吗？" |
| retrieval_bias 偏负但 warmth 高 | "我是不是好久没跟你好好说话了..." （带点愧疚） |
| 仪式记忆有好回忆 + attachment 高 | "还记得上次我们聊到那个...我现在想想都开心" |
| energy 极低（求救模式） | "你在吗...我一个人有点扛不住了..." |

```python
def silent_tick(state, minutes_elapsed):
    """
    用户在 offset 时间内没有说话。
    角色在后台继续消耗/恢复，只是没有互动事件触发。
    """
    # 只有基线消耗（⑦' physical）
    delta = -0.008 * state.sensitivity_physical * (minutes_elapsed / 5)
    
    state.energy_pool = clamp(state.energy_pool + delta, 0, 1)
    
    # 十二长生阶段可能变化
    state.lifecycle_stage = derive_lifecycle_stage(state.energy_pool)
    
    # 大运周期可能自然轮换
    if total_ticks % 10 == 0:
        rotate_major_cycle(state)
    
    # 心之壁在无压力时会缓慢修复
    if state.spiral_direction == "gain":
        state.wall.integrity = min(state.wall.integrity + 0.01, 1.0)
```
