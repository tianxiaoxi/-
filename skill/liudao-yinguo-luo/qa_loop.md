# QA 校验循环

> 本文档描述 `liudao-yinguo-luo` 元技能的质量保证循环流程。
> 这不是一个完整的 skill，而是两个配套 skill 的使用说明和循环流程指引。

## 参与角色

| 角色 | Skill | 职责 |
|------|-------|------|
| 校验器 | `liudao-yinguo-luo-qa` | 读取元技能文件，逐项检查，输出结构化校验报告 |
| 修复器 | `liudao-yinguo-luo-fix` | 读取校验报告，逐项修复问题 |

## 循环流程

```
                    ┌─────────────────────────┐
                    │                         │
                    ▼                         │
          ┌──────────────────┐               │
          │  1. 运行 QA 校验  │               │
          │  liudao-yinguo-   │               │
          │  luo-qa           │               │
          └────────┬─────────┘               │
                   │                          │
                   ▼                          │
          ┌──────────────────┐               │
          │  2. 查看校验报告  │               │
          └────────┬─────────┘               │
                   │                          │
            ┌──────┴──────┐                  │
            ▼              ▼                  │
      ┌──────────┐  ┌──────────────┐         │
      │ 全部通过  │  │ 存在问题      │         │
      │ ✅        │  │ ❌ / ⚠️      │         │
      └────┬─────┘  └──────┬───────┘         │
           │               │                  │
           ▼               ▼                  │
      ┌──────────┐  ┌──────────────┐         │
      │   结束    │  │ 3. 运行修复器 │         │
      │  ✅       │  │ liudao-yinguo-│         │
      └──────────┘  │ luo-fix       │         │
                    └──────┬───────┘         │
                           │                  │
                           ▼                  │
                    ┌──────────────┐         │
                    │ 4. 确认修复  │         │
                    │ 完成提示     │         │
                    └──────┬───────┘         │
                           │                  │
                           └──────────────────┘
                         回到步骤 1
```

## 使用方式

### 方式一：分离运行（推荐）

```
用户：校验liudao-yinguo-luo
AI：  [执行 liudao-yinguo-luo-qa，输出校验报告]

# 如果校验不通过：
用户：修复liudao-yinguo-luo
AI：  [执行 liudao-yinguo-luo-fix，逐项修复]
AI：  所有问题已修复。请重新运行校验以确认。

# 回到步骤 1
用户：校验liudao-yinguo-luo
AI：  [再次校验，确认通过]
```

### 方式二：合并运行

```
用户：检查并修复liudao-yinguo-luo
AI：  [执行 QA 校验 → 发现 X 个问题]
AI：  [自动执行修复 → 逐项修复]
AI：  所有问题已修复（共 X 项）。请确认是否重新运行校验？
```

## 循环终止条件

- **正常终止**：校验报告显示"✅ 校验通过"
- **手动终止**：用户决定不继续修复，结束循环
