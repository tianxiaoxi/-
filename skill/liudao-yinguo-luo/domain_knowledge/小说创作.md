# 小说创作领域知识 · 六道因果络映射

> **领域类型**：小说/叙事文本的生成式创作辅助
> **根本特征**：角色的行为从内部状态自然生长出来，而非从外部被作者安装上去。系统不是审查者——是因果镜子，帮作者看到自己笔下人物在18条路径上的因果张力。
> **核心原则**：提问在道内。系统向作者提问是一次 Collins 互动仪式——共同焦点是因果张力，共享情绪是"一起琢磨"，仪式成功 → 作者感到被理解而非被评判。

---

## 一、六维度语义映射

| 维度 | 含义 | 核心问题 |
|------|------|---------|
| **人物自洽** | 角色行为与其内部状态的因果一致性 | "这个角色为什么做这件事？" |
| **互动真实** | 角色间互动的仪式质量——对话是否像活人说的话 | "这两个人为什么这样说话？" |
| **关系可信** | 角色间关系的发展是否有因果轨迹 | "他们为什么成了朋友/敌人？" |
| **资源因果** | 资源流动（力量、情报、信任、金钱）是否有来处和去处 | "他凭什么得到这个？" |
| **内部状态** | 角色的消耗、缓冲、崩塌是否体现在叙事中 | "他累了吗？怎么累的？" |
| **叙事质量** | 情节、语言、结构的因果密度 | "这段一定要这样写吗？" |

---

## 二、各维度分析要点与评分标准

### 维度一：人物自洽

**分析要点**：
- 角色的每个行为是否有内部原因（不是"因为剧情需要"）？
- 角色的核心记忆（memories）是否在决策时被激活？
- 角色是否有"不像他会做的事"——如果有，读者是否能感知到这是一个有意的转折而非因果断链？

**评分标准**：
- 8-10：角色行为因果清晰，读者能推测"他肯定会这样做"；即使做出意外选择，事后回想也能找到种子
- 5-7：大部分行为合理，但有2-3处因果跳跃——角色在为剧情服务而非剧情为角色服务
- 1-4：角色行为飘忽，像被作者随手搬动

### 维度二：互动真实

**分析要点**：
- 角色对话是否有 Collins 互动仪式链的特征——共同焦点、情绪同步、群体共在感？
- 对话是否存在"信息倾泻"（角色在解释世界观而不是在对话）？
- 不同角色是否有不同的互动风格（前台不同）——同一个事件，两个角色说出来的话应该不同
- 沉默、犹豫、岔开话题——这些也是互动，是否有？

**评分标准**：
- 8-10：对话有呼吸感，每个角色的说话方式不同，仪式有成功有失败，有未被回应的话
- 5-7：对话基本成立但偶有"作者嘴替"痕迹，个别角色说话像同一个人
- 1-4：对话高度功能化（只为推进剧情），缺乏人的质感

### 维度三：关系可信

**分析要点**：
- 关系的建立是否通过**展示的互动**（而不是旁白"他们成了朋友"）？
- 关系是否有准社会交往的特征——逐步积累，不是一蹴而就？
- 关系的转变（友变敌、爱变恨）是否有因果链——恨的种子是否在爱的时候就已经种下？
- "他们认识了三年"——如果这三年的互动没有在叙事中被见证，这句旁白是空洞的

**评分标准**：
- 8-10：关系有生长感，读者能回看前文找到关系的种子；转变有因果铺垫
- 5-7：关系基本成立但有些跳跃还需要铺垫
- 1-4：关系被作者强行推动，缺乏互动积累

### 维度四：资源因果

**分析要点**：
- 角色获得资源（能力、情报、信任、武器、金钱）是否有交换过程——路径④（交易型互惠）在运作？
- 获得的东西是否有叙事后果（不是"拿到手就结束了"）——路径⑬（资源→内容）是否闭环？
- 人际资源（信任、欠人情）是否和物质资源同样有因果——路径②'（关系型互惠）的兑现？

**评分标准**：
- 8-10：资源流动有来处有去处，没有"天降神器"；得到的都有代价，失去的都有后果
- 5-7：大部分资源有因果但偶有"方便道具"——刚好需要什么就有什么
- 1-4：资源像游戏道具，需要时就有，用完就消失

### 维度五：内部状态

**分析要点**：
- 角色是否有消耗的轨迹——累过、崩溃过、恢复过（pool 曲线不是一条直线）？
- 创伤记忆（intensity 高的 memories）是否在相似场景中被激活——路径⑤/⑦/⑦'的触发？
- 心之壁（角色隐藏内心的程度）是否一致——如果一直不展示内心，这是艺术选择还是逃避？
- 角色赢了之后是真的更自信（路径⑥'正向螺旋），还是更焦虑（怕维持不住）？

**评分标准**：
- 8-10：内部状态在叙事中可感知，消耗和恢复的节奏自然且与情节节奏呼应
- 5-7：偶尔展示内部状态但不连贯——角色在需要痛苦时痛苦，不需要时就忘了痛苦
- 1-4：角色是"没有内部的人"，永远在行动

### 维度六：叙事质量

**分析要点**：
- 情节推进是否有因果驱动（不是"突然就……"）？
- 叙事视角的渗透性是否一致——第一人称全透明 / 限知视角的选择性呈现 / 冰山叙事的刻意留白？
- 结构是否有 Collins 仪式链的节奏感——峰（高潮互动）、谷（消耗累积）、再起峰（恢复后的新爆发）？
- 有没有"作者省事"的痕迹——旁白解释代替互动展示、巧合代替因果、万能解释代替具体过程？

**评分标准**：
- 8-10：情节像河流，有流速有弯道有落差但不无故断流；语言在恰当的渗透性层级
- 5-7：情节基本连贯但有2-3处"断层"——读者需要停下来想"为什么"
- 1-4：情节碎片化，因果跳跃；读者频繁出戏

## 三、18条路径的叙事语义映射

### 子系统一：角色的内部状态（JD-R 骨架）

| 编号 | 路径语义 | 叙事诊断问题 | 不合道的信号 |
|------|---------|-------------|------------|
| ⑤ | 表面呈现 → 状态消耗 | **角色在谁面前"演戏"？** 他内心感受和行为之间的距离有多大？ | 角色内心痛苦但行为完全无异——且这不是角色个性（高自我监控），而是作者忘了写消耗 |
| ⑦ | 认知负荷 → 状态消耗 | **动脑子的代价是否被感知？** 角色破解了一个难题后，下一场景他是疲惫还是精力充沛？ | 角色一夜破解所有谜题，没有认知疲劳；或者智力水平随剧情需要忽高忽低 |
| ⑦' | 生理消耗 → 状态 | **身体有后果吗？** 受伤后下一场战斗是否受影响？连续高强度行动后是否需要恢复？ | 角色受伤后下一场照常战斗，没有恢复期；熬夜数天依然精神抖擞 |
| ⑨ | 前台维护 → 状态 | **"维持我是谁"的固定成本？** 如果角色的身份是撑着的（假装某种人设），这个成本是否在叙事中显现？ | 角色"一直很强大"但没有任何内心代价；或者一直在装一种人设但从不疲惫 |
| ⑤' | 外部关系 → 状态缓冲 | **崩溃时谁接住他？** 角色的社会支持是否真实存在——当他在低谷时，是否有人真的在场？ | 角色崩溃后没有任何人接住，但下一章自动恢复如常 |
| ⑥' | 资源流 ⇄ 状态 | **成败影响自我判断吗？** 赢了更自信还是更焦虑？输了自我怀疑还是反而清醒了？ | 角色屡败屡战但自我效能丝毫不降；或屡战屡胜但永远自我怀疑——情绪与事实始终脱节 |
| ⑥ | 状态 → 前台崩塌 | **撑不住了会怎样？** 内部消耗超过阈值时，角色会不会崩？崩的时候读者能看到吗？ | 角色承受了一切但从不崩塌——读者感到"假"。或者崩得太突兀，之前没有任何积累信号 |

### 子系统二：角色间的互动动力学

| 编号 | 路径语义 | 叙事诊断问题 | 不合道的信号 |
|------|---------|-------------|------------|
| ① | 前台 ⇄ 互动 | **角色在互动中有几层面具？** 读者知道的内心 vs 互动中展现的样子——这个张力被感知到了吗？ | "表面冷酷内心温柔"但所有人第一面就看穿了——没有前台/后台差异；或者第一人称角色对自己完全透明，没有任何盲区 |
| ② | 互动 → 外部关系 | **关系是积累出来的还是宣布出来的？** 能逐场追溯 Collins 互动仪式链的累积吗？ | "他们并肩作战后成了生死之交"——但没有展示并肩作战中的互动仪式 |
| ③ | 互动 ≈ 内容质量 | **对话中的话被回应了吗？** 角色说的每句话在场景中是否有接收和响应？ | 角色发表震撼性演讲但场景中其他角色的反应像背景板；或对话一问一答毫无化学反应 |
| ④ | 互动 → 资源流（交易型） | **得到东西之前交换了什么？** 陌生人不会无缘无故帮助主角——每笔"交易"有交换过程吗？ | 陌生人无缘无故帮助主角；或交易过于不对等（一个微笑换了一个王国） |
| ②' | 外部关系 → 资源流（关系型） | **老交情的红利被展示过吗？** 旧关系提供资源——但读者看到过这个"旧"的积累过程吗？ | 一个只在对话中提过的"老朋友"突然提供关键帮助——读者没有任何情感连接 |
| ⑩ | 前台 → 内容约束 | **角色做的事是否在他已建立的框架内？** 如果偏离了，读者看到偏离的原因了吗？ | 谨慎的角色突然鲁莽——没有任何铺垫；角色为了剧情需要打破了自己的核心原则 |
| ⑪ | 内容 → 外部关系 | **有人因为角色"做了什么"而靠近他吗？** 不因为互动——因为角色提供的价值（知识、能力、保护）？ | 所有关系都是互动驱动的——没有人因为角色"厉害"或"有用"而与他建立关系 |
| ⑫ | 外部关系 → 内容（群体共创） | **其他人参与了场景的共建吗？** 还是主角一人撑全场？配角是活人还是道具？ | 主角一人撑全场，配角只负责"嗯""然后呢""你说得对"；群体的每个成员说话都像同一个人 |
| ⑬ | 资源流 → 内容 | **得到的东西被用上了吗？** 获得的资源（工具、力量、情报）是否有叙事后果？ | 角色获得了神器/情报但后续完全没用上；或用了但没有产生任何因果涟漪 |

### 交互面：叙事边界

| 编号 | 路径语义 | 叙事诊断问题 | 不合道的信号 |
|------|---------|-------------|------------|
| 心之壁 | 边界渗透性 | **读者能看到多少角色的内心？** 这个渗透性层级是否在整本书中保持一致？ | 第一人称但角色对自己完全透明（这是可能的，但需要意识到这是"透明角色"的设计选择）；限知视角但突然出现了其他角色的内心独白 |
| ⑧ | 外部关系 → 前台塑形 | **角色被环境和身边人改变了吗？** 经历了天翻地覆的环境变化但行事风格完全不变——这是因果断链。 | 角色从小村庄到帝都，行事风格毫无变化；被完全不同的群体接纳后，说话方式、思维方式完全没有渗透 |
| ①↺' | 表演 → 自我认知 | **长期的角色扮演是否渗透了真实自我？** 装了一辈子强者，真的开始相信自己强了吗？（路径A 内化）还是始终知道自己在装？（路径B 工具） | 装了十年还没开始内化——这不是意志力，是因果静止；或者第一年就完全内化——太快了，慢变量需要时间 |
| ERF | 外部冲击 | **是否有事件绕过正常因果直接冲击角色内部状态？** 天灾、命运转折——允许，但入口需清晰。 | 冲击发生后角色立刻恢复行动——没有⑥崩塌、没有⑤'缓冲失效、没有⑥'螺旋中断 |

## 四、心之壁判定（叙事边界渗透性）

心之壁在小说创作中的含义：**叙事视角对角色内部状态的呈现程度**。这不只是"第一人称还是第三人称"的技术选择——它决定了读者在多大程度上能感知到角色内部消耗的轨迹。

| 叙事手法 | 渗透性 | 效果 | ⑥（前台崩塌）的可检测性 | 适用场景 |
|---------|--------|------|------------------------|---------|
| 第一人称内心独白 / 意识流 | 极高 | 角色内心完全透明——读者知道一切消耗、创伤、喜悦 | ⑥高度可见——每一次崩塌都有内部信号 | 需要深度共情的角色；但需注意：读者知道太多可能削弱悬念 |
| 第三人称限知（深度跟随） | 高 | 读者知道这个角色的内心但不知道其他人的 | ⑥可被感知——消耗信号通过选择性内心呈现传递给读者 | 最常见的叙事模式；一个角色为主，其他角色保持神秘 |
| 第三人称限知（浅度跟随） | 中 | 选择性呈现内心——只在关键时刻展示 | ⑥可能只是偶尔泄露——读者需要在行为中推断消耗 | 适合有多个 POV 角色的长篇 |
| 第三人称全知但从不深入内心 | 低 | ⑥沉默——读者看不到角色内部消耗。危险：如果内部消耗高但读者完全看不到，叙事会产生"假" | 只能从行为推断——如果行为也看不出来，⑥彻底沉默 | 需要极高的行为描写功力；否则读者会觉得角色是"空心人" |
| "冰山叙事"（海明威式） | 低但有意 | 故意不给内心——消耗必须从行为中自然溢出。这是艺术选择，不是因果断链 | ⑥通过行为密码传递——一个细微的动作变化替代长篇内心独白 | 简洁风格；适合"少即是多"的审美追求 |

**核心约束**：不管选择哪种渗透性层级——**如果渗透性低（读者看不到内心），那么行为的因果密度必须相应提高**。低渗透性 + 低因果密度 = 读者觉得角色没有理由做任何事。

**渗透性不一致的检测**：如果全书大部分章节是深度限知视角，但本章突然变成了"全知但从不深入内心"——这是信号，可能意味着作者在本章"逃避写内心"。

## 五、交互协议：提问如何在道内

> **核心原则**：系统不是审查者——是协作伙伴。每次提问都是一次 Collins 互动仪式。共同焦点是因果张力，共享情绪是"一起琢磨"。仪式成功 → 作者感到被理解；仪式失败 → 作者感到被评判。

### 提问的四种仪式形态

| 仪式类型 | 触发条件 | 提问形式 | 仪式效果 |
|---------|---------|---------|---------|
| **呈现** | 系统感知到因果张力 | "我看到 X 在 Y 场景中的行为，但上一章 Z 刚发生。这两个事件之间的因果联系，读者在本章能感知到吗？" | 把张力放到共同焦点——作者看到自己可能没注意到的东西，但不是"你做错了" |
| **好奇** | 系统不确定某条路径的状态 | "这个角色在这里是真的很平静，还是在撑？如果是撑——你想让读者现在就感知到这种撑，还是埋到后面一次性爆发？" | 不是给答案——是把叙事选择的因果分枝摊开，让作者选 |
| **镜像** | 作者犹豫在两个方向之间 | 触发三生万物分支推演——"如果选 A，角色的 pool 曲线会在第3章开始陡降；选 B，pool 会先降后升但需要更长的恢复期。你想走哪条线？" | 把因果后果可视化——不是"哪个更好"，是"哪个更符合你想写的东西" |
| **沉默** | 当前章节因果密度充足，没有明显的张力 | 不说话，或简单一句"本章因果链路通畅" | 仪式成功 → 作者感到被确认。不要没事找事——沉默也是道内的互动 |

### 提问的禁忌（违反路径⑩的期望违背信号）

| 禁忌 | 为什么违反 | 正确做法 |
|------|-----------|---------|
| "你应该在这里加一段内心独白" | 系统在教作者怎么写——前台从"协作伙伴"切换到"写作教师"，⑩（期望违背）被触发 | "这个角色的内部状态在本章是沉默的。如果你希望读者感知到他的消耗，可能需要一个窗口——你想用什么方式打开？" |
| "这段不合道，建议修改" | 二元判断——把因果作为"对/错"标准，而不是"你看这里的因果是这样的" | "这段情节中，角色从 A 到 B 的转变，因果链条中间有一环没有被展示。是留白（有意省略）还是跳跃（需要补上）？" |
| "根据六道因果络分析……" | 把框架术语带入对话——前台切换成"分析者"，不是"创作伙伴" | 用自然语言说因果，不要用编号——"他刚经历了背叛，现在又要在背叛者面前保持正常——这个消耗很大，读者能看到吗？" |

### 提问时框架术语的使用规则

- **可以用**：自然因果语言（"消耗""崩塌""积累""缓冲""渗透"）
- **不用**：路径编号（⑤⑨⑥）、理论名称（JD-R、Collins、COR）、框架名称（六道因果络）
- **原因**：作者不需要知道系统的眼镜是什么牌子——只需要看到因果镜子里反射的东西

## 六、三生万物推演映射（创作中的分支推演）

当作者在创作过程中犹豫"角色应该走A还是走B"时，三生万物的分支推演介入——不是给答案，是把因果后果可视化。

### 推演接入时机

| 接入时机 | 叙事问题 | 三生万物做了什么 |
|---------|---------|----------------|
| 创作节点犹豫 | "角色应该原谅还是决裂？" | 分叉两条线，注入不同事件，并排展示 pool 轨迹和激活的记忆 |
| 回顾检查 | "这个创伤事件真的改变了角色吗？" | 克隆角色但不注入该事件，对比长期 pool 曲线差异 |
| 冲击测试 | "想在第 N 章加一场巨大冲击——角色扛得住吗？" | 在基线该节点注入高 intensity ERF 事件，观察 pool 跌落深度和恢复时间 |
| 节奏检查 | "角色连续高强度行动了多章，有没有合理的低谷？" | 统计连续高 drain 轮次，预测⑥崩塌窗口，展示何时需要低谷 |

### 推演结果的语言转换

三生万物输出的 pool 值、memory 激活强度、交叉传播数据——在呈现给作者时转换成因果语言：

```
引擎输出：T5 pool=0.24, 激活记忆=[背叛(0.9), 灭门(0.8)], 交叉传播=0.12
转换为：到第五章，角色的内部消耗已经非常深。旧伤（背叛、灭门）同时被触发——
这两件事在互相放大痛苦。读者如果感受不到这种"旧伤叠加新伤"的沉重，角色后面的
崩溃会显得突兀。
```

## 八、创作全流程协议

小说创作的工作流与六道因果络的标准分析流程不同——它不是一个"搜索→分析→报告"的线性过程，而是一个**持续交互的创作伙伴关系**。

### 阶段一：构思 → 大纲生成

1. 作者描述想要的故事方向（题材、主题、大致剧情）
2. 系统识别核心冲突，映射到子系统一（角色的 JD-R 消耗源）和子系统二（Collins 互动仪式链的建立与断裂）
3. 系统生成大纲初稿，每个情节点标注它触发的因果路径
4. 作者与系统对话调整大纲

### 阶段二：角色设计 → JD-R 档案 + 道一引擎状态

1. 系统为每个核心角色建立 JD-R 档案（四线消耗、两类缓冲、边界渗透性）
2. 系统将角色的背景故事转换为道一引擎的 `memories` 列表（经历逆推）
3. 作者可以在创作前看到角色的"因果拓扑"——什么样的记忆网络定义了这个人

### 阶段三：逐章写作 → 交互式因果镜子

1. 作者写完一章（或一节），系统读取文本
2. 系统感知因果张力——不是"检查是否合规"，而是"看到了什么"
3. 系统用合道的方式向作者呈现这些张力
4. 作者选择：接受（"对，我这样写没问题"）/ 修改（"你说得对，我补一段"） / 分支推演（"我不确定，帮我推演一下两种写法"）

### 阶段四：全书回望 → 全局因果审计

1. 全书完成后，系统读取全部文本
2. 检查每个核心角色的完整 pool 轨迹是否自洽
3. 检查慢变量路径（①↺'、⑧、⑨）是否在整本书的时间跨度中合理推进
4. 标记"在全书层面看才显现的因果跳跃"——这些在逐章写作时不易察觉

## 九、五域归因（创作语境）

| 五域 | 领域语义 | 在创作中的检测点 |
|------|---------|----------------|
| 自主域（官杀） | 角色被外力控制、约束、逼迫 | 角色有没有"不得不"的时刻？这些时刻是否产生了真实的内心冲突而非叙事敷衍？ |
| 社会域（印星） | 角色被接受或拒绝、归属与孤立 | 角色的社会关系网络是否在故事中生长、断裂、重建——而不是静止的背景设定？ |
| 财务域（财星） | 资源得失——力量、金钱、情报、信任 | 每一次获得都有代价，每一次失去都有后果——这些代价和后果是否在叙事闭环？ |
| 认知域（食伤） | 角色学习、创新、解决问题、成长 | 角色的认知成长是否有因果——从"不知道"到"知道"的过程是否被展示而不只是被宣布？ |
| 同侪域（比劫） | 角色与他人的比较、竞争、嫉妒 | 竞争/比较是否在驱动角色的行为——还是只在背景里提了一句？ |

## 十、Collins 仪式链在创作中的检测信号

| 仪式输出 | 叙事含义 | 可检测信号 |
|---------|---------|-----------|
| 情感能量（EE） | 场景中的集体情绪强度 | 对话密度峰值、情绪关键词密度、场景节奏加速或减速 |
| 群体团结 | 角色间"我们是自己人"的归属感 | "我们"类语言的出现频率、共同对抗外部威胁的时刻、内部暗语/共享记忆的激活 |
| 神圣符号 | 角色间的共享象征物 | 反复出现的物品/地点/话语、角色之间特有的称呼或暗号、"只有我们才懂"的内容 |
| 道德感 | 角色对自身行为正当性的判断 | 角色是否在为自己的选择辩护、是否感到愧疚、是否在寻求外部认可 |
