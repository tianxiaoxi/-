# 虚拟主播领域知识 · 六道因果络映射

> **领域类型**：虚拟主播（VTuber）—— 以虚拟形象进行直播的主播
> **适用平台**：B站/YouTube/Niconico
> **根本特征**：前-后台分界为虚拟形象 vs 中之人（二分），心之壁由皮套建立的物理性屏障

---

## 一、六维度语义映射

| 维度 | 含义 | 核心问题 |
|------|------|---------|
| **人设定位** | 主播选择呈现给观众的形象（Goffman 前台） | "她是谁？" |
| **互动效果** | 与观众的实时互动质量——弹幕回应、氛围营造 | "她跟观众怎么说话？" |
| **粉丝关系** | 观众与主播之间的准社会关系强度与群体结构 | "粉丝为什么留下？" |
| **流水营收** | 礼物收入、付费转化 | "为什么有人愿意花钱？" |
| **个人状态** | 主播的心理能量、情绪消耗、倦怠程度 | "她累不累？" |
| **内容质量** | 直播话题、节目编排、信息密度 | "她聊的东西有没有价值？" |

---

## 二、各维度分析要点与评分标准

### 维度一：人设定位

**分析要点**：
- 前台形象是什么？有没有明确的角色设定？
- 人设一致性——在不同平台上形象是否统一？
- 是否存在人设偏移信号（近期形象与早期形象有差异）？

**搜索线索对应**：搜索1（基本信息） + 搜索5（争议/变化）

**评分标准**：
- 8-10：人设鲜明、一致性强、有独特的记忆点
- 5-7：人设基本清楚但不够鲜明，或偶有不一致
- 1-4：人设模糊、频繁变动、或"塌房"风险

---

### 维度二：互动效果

**分析要点**：
- 互动风格——冷静分析型 / 活泼跳跃型 / 温柔陪伴型？
- 弹幕回应模式——选择性回应 / 几乎全回 / 选择性忽略？
- 互动中的情绪能量——能否产生 Collins 互动仪式链中的"集体兴奋"？
- 是否存在表面表演（情绪劳动）信号——"硬撑活泼"、"强颜欢笑"？

**搜索线索对应**：搜索2（近期直播/动态） + 搜索3（粉丝评价与讨论）

**评分标准**：
- 8-10：互动自然流畅、弹幕活跃、经常出现集体兴奋时刻
- 5-7：互动基本合格但缺乏爆点，或情商劳动信号偶现
- 1-4：互动生硬、大量表面表演、弹幕冷淡

---

### 维度三：粉丝关系

**分析要点**：
- 粉丝关系类型——情感驱动（准社会关系强）还是内容驱动？
- 核心粉 vs 边缘粉比例（从讨论热度、超话活跃度推断）
- 是否存在关系型互惠信号——"老粉无条件支持"？
- 社群文化类型——事业粉 / 萌萌人 / 乐子人 / 竞技粉？

**搜索线索对应**：搜索3（粉丝评价与讨论） + 搜索7（社群/粉丝群体）

**评分标准**：
- 8-10：粉丝忠诚度高、社群凝聚力强、形成独特粉丝文化
- 5-7：有稳定粉丝群但凝聚力一般、社群文化未形成
- 1-4：粉丝流失严重、缺乏核心粉丝、负面评价居多

---

### 维度四：流水营收

**分析要点**：
- 营收主要来源——交易型互惠（互动即时转化）还是关系型互惠（长期粉丝支撑）？
- 营收稳定性——持续有收入还是大起大落？
- 是否存在过度依赖少数"榜一"的风险？

**搜索线索对应**：搜索4（收入/营收相关）

**评分标准**：
- 8-10：营收稳健、多元来源、增长趋势
- 5-7：营收尚可但波动大、或依赖少数人
- 1-4：营收低迷、持续下滑、无法覆盖成本

---

### 维度五：个人状态

**分析要点**：
- 是否有倦怠信号——"停播"、"休息"、"状态不好"等公开言论？
- 情绪失调信号——观众是否察觉到"演"的痕迹？
- SDT 自主性信号——主播是否表达了"不得不播"的被动感？
- 社会支持缓冲——粉丝关系是否有效缓冲了状态消耗？

**搜索线索对应**：搜索5（争议/负面/状态相关）——此维度高度依赖搜索5

**特别注意**：如果公开信息中状态信号持续为负面但前台形象始终"稳定"（心之壁厚的表现），这是更危险的假性稳定——需要明确标记为"⑥（状态→人设崩塌）因心之壁厚而沉默"。

**评分标准**：
- 8-10：状态良好、自主性强、情绪能量充沛
- 5-7：偶有疲惫信号、但仍能维持
- 1-4：明显倦怠、多次停播、情绪失调信号频出

---

### 维度六：内容质量

**分析要点**：
- 内容类型——杂谈 / 游戏 / 唱歌 / 知识 / ASMR？
- 话题丰富度——是否有足够的内容储备避免空档？
- 认知负荷信号——是否频繁出现"不知道聊什么"？
- 人设×内容的匹配度——内容是否在叙事同一性框架内（⑩ 人设→内容·叙事约束）？

**搜索线索对应**：搜索6（内容特点分析）

**评分标准**：
- 8-10：内容有深度/特色、话题丰富、与人设高度一致
- 5-7：内容合格但缺乏差异化、偶有话题枯竭
- 1-4：内容空洞、高度依赖互动填内容、与人设矛盾

## 五、心之壁判定标准（前台-后台边界渗透性）

判断主播的前台角色与真实自我之间的边界厚度：

| 信号 | 解读 |
|------|------|
| 前台形象稳定 + 后台信息从不泄露 | **心之壁厚**——消耗可能存在但表面看不出来（高风险假性稳定） |
| 下播后说话方式也像直播 / 朋友说"你越来越像直播间里的你了" | **心之壁薄**——①↺'（表演→自我认知内化）正在发生，前-后台融合 |
| 停播/情绪崩溃 / 突然转型 | **心之壁被打破**——积累的消耗一次性释放 |

**⑥沉默风险检测方法**：
- 个人状态消耗信号持续存在但前台形象始终稳定 → 标记为"可能存在假性稳定——⑥因心之壁厚而沉默"

**特殊说明**：虚拟主播的心之壁是**物理性的**——皮套建立了天然的视觉屏障，中之人信息被物理性隔离。

## 六、时间节奏驱动力映射

| 驱动力 | 对应关系 | 在节奏中的表现 |
|--------|---------|-------------|
| Collins 互动仪式链的形成与断裂 | ①②③④ 的底层动力 | 仪式成功 → 节奏峰；仪式失败 → 节奏谷；再启动 → 再起峰 |
| ⑤ 情绪劳动消耗速率 | ⑤ 互动→状态 | 决定"峰能撑多久"和"谷有多深"，表面表演越重消耗斜率越陡 |
| 心之壁厚度 | 约束⑥可检测、影响⑨轨迹 | 薄 → 谷段后台泄露可见（波动）；厚 → 谷段无外显信号（平坦但危险） |
| ⑦ 认知负荷空档 | ⑦ 内容→状态 | 话题断档 = 节奏断点，空档频率决定节奏密度 |
| ⑥' 营收⇄状态反馈 | ⑥' | 正向锁→峰后有惯性上冲；负向锁→峰后继谷更深 |

> 如果心之壁判定为厚 + 全程节奏描述为"稳定" → 标注为"⚠ 可能为厚壁假性平板"
> 如果搜索结果中时间信息不足 → 标注为"时间节奏信息不足，无法判定"

## 七、社群/体系维度分析指标（粉丝群体）

> 粉丝群体存在独立于个体关系总和的群体动力学（Lewin/Collins 成立），但具体的社群文化类型分类、指标阈值属于待验证假说。分析时使用试探性表述。

| 指标 | 参考区间 | 风险信号 |
|------|---------|---------|
| 弹幕来源集中度 | Top 20% 占比 20-40% | 过高→封闭，过低→无凝聚力 |
| 社群文化稳定性 | 弹幕关键词聚类稳定 | 剧变→社群在换血，⑧（粉丝→人设·粉圈塑形）正在发生 |
| 新人融入度 | 新粉被回应后留存率高 | 低→社群封闭或互动排斥新人 |
| 梗文化密度 | 有原创梗且传播速度快 | 无→群体缺乏共创能力 |

> **社群文化类型（事业粉/萌萌人/乐子人/竞技粉）**：此分类来自 V 圈社区话术，尚未学术操作化。分析时可用于定性描述，但勿将其作为确定的诊断类别。搜索结果中若出现相关话术，标注为"社群自述类型"。

## 十一、历史仪式记忆检索

（分析同一虚拟主播时，检索其历史分析报告以构建仪式链轨迹）

- **检索范围**：`analysis_reports/` 目录下该主播的历史分析报告，以及平台公开数据(粉丝数曲线、SC收入曲线、舰长数历史)、录播/VOD存档中的关键事件标注、粉丝wiki/萌娘百科条目中的时间线
- **对比维度**：同域仪式的连续成功/失败次数、炎上恢复周期变化、内容创新-粉丝反应的时间差变化、人设的域敏感性漂移
- **检索关键词**：`{主播名} {事件类型} 历史 回顾` `/` `{主播名} timeline archive`
- **虚拟主播特有检索源**：
  - Playboard/VTuber Stats等第三方SC/收入追踪平台的历史曲线
  - 平台粉丝数公开历史(如YouTube: Social Blade; B站: 粉丝数曲线)
  - 萌娘百科/粉丝wiki中的大事记时间线
  - NGA/VTuber吧/Reddit r/VirtualYoutubers中的月度/季度讨论汇总
  - 录播/VOD频道中关键直播的切片标注
  - 二创作品(Pixiv/DeviantArt/B站)的季度产出量变化
  - 联动合作时间线(与哪些主播、频率、效果)
- **轨迹信号**：
  - 同域连续炎上/争议≥3 → 社群预期焦虑/创作者资源预支(减少冒险内容、趋于保守)
  - 炎上恢复周期逐次延长（第一次炎上1周恢复、第二次1个月、第三次永久失粉） → 粉丝信任衰减效应，对应⑤'缓冲耗竭
  - 人设域敏感性单向漂移（如从"清新可爱"被粉丝推至"性感路线"，但主播抵触） → 人设-自我意义建构冲突，对应⑧路径异常
  - 直播频次下降 + SC收入不降 → ②'关系型互惠主导，但⑦'生理消耗积累未在营收端显现（⑥前兆）
  - 同期生出道粉丝数从并列到落后>30%且启动联动补救无效 → 同侪域失败信号，可能触发①↺'自我认知偏移
