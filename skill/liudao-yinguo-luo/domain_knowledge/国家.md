# 国家领域知识 · 六道因果络映射

> **领域类型**：主权国家/高度自治地区
> **时间尺度**：月-代际（极慢变量）——大部分路径需以十年为单位观察
> **数据来源优先级**：结构化指标优先于媒体报道（IMF/WB/FSI/CPI/Freedom House/Soft Power 30等）
> **根本特征**：心之壁是**系统性的**——制度性的信息管控体系，由技术层、制度层、文化层三层构成

---

## 一、六维度语义映射

| 维度 | 含义 | 核心问题 |
|------|------|---------|
| **国家形象** | 国家在国际舞台上的自我呈现——外交叙事、品牌定位、领导人形象 | "这个国家在国际上是'谁'？" |
| **外交互动** | 与世界各国/国际组织的互动质量——峰会表现、访问外交、多边参与 | "它怎么跟世界打交道？" |
| **盟友关系** | 战略伙伴、军事同盟、经济伙伴网络的强度与结构 | "谁站在它这边，为什么？" |
| **经济/贸易** | GDP增长、贸易结构、经济韧性、外资信心 | "它的经济健康吗？谁在给它'付费'？" |
| **国内治理** | 政权稳定性、社会凝聚力、公共服务、资源承载 | "它的内部系统有多稳固？" |
| **软实力输出** | 文化影响力、科技创新、国际话语权、价值观吸引力 | "它向世界提供了什么价值？" |

### 国家 vs 其他分析对象的根本差异

| 维度 | 主播 | 品牌/公司 | 国家 |
|------|------|---------|------|
| **前台载体** | 声音+画面 | 品牌叙事+产品 | 外交声明+领导人+文化输出 |
| **后台性质** | 个人心理 | 组织文化 | 治理系统（制度性的） |
| **心之壁性质** | 个人心理机制 | PR管控机制 | 系统性信息管控（技术+制度+文化三层） |
| **时间尺度** | 秒-月 | 月-年 | 月-代际（极慢变量） |
| **⑥后台崩塌** | 情绪崩溃/停播 | 丑闻/破产 | 政权崩溃/革命/国家失败 |
| **数据来源** | 弹幕/论坛 | 财报/Glassdoor | IMF/世界银行/FSI/CPI/联合国/Wikipedia |
| **社群** | 粉丝圈 | 品牌社区 | 国际体系/联盟/多边组织 |

## 二、各维度分析要点与评分标准

### 维度一：国家形象

**分析要点**：
- 国际叙事是什么？——民主灯塔 / 和平崛起 / 欧洲心脏 / 不稳定国家？
- 形象一致性——在不同议题(人权/贸易/气候)和国际场合上的形象是否统一？
- 是否存在形象偏移信号（近期定位与历史形象有显著差异）？
- 领导人公众形象是否与国家形象一致？
- **国家特有指标**：Anholt Nation Brands Index 排名变化、国际媒体情感分析趋势

**评分标准**：
- 8-10：国家形象鲜明、国际叙事统一、有独特的国际辨识度
- 5-7：形象基本清楚但不够鲜明，或偶有叙事矛盾
- 1-4：形象模糊、频繁更换外交叙事、或陷入极端负面标签（"流氓国家"/"失败国家"）

---

### 维度二：外交互动

**分析要点**：
- 外交互动风格——主导型 / 协商型 / 平衡型 / 孤立型？
- 外交活跃度——峰会参与频率、国事访问互访比例、多边场合发言频率
- 能否通过外交互动产生 Collins 互动仪式链中的"国际团结感"（如气候峰会联合声明、联合军事演习的象征意义）？
- 是否存在表面表演信号——外交辞令与实际政策之间的矛盾？

> Collins 互动仪式链在国家层面表现为**外交仪式**——G7/G20 峰会、国事访问红毯仪式、联合军演、联合国大会演讲。仪式成功 = 联合声明顺利通过 + 国际媒体正面报道；仪式失败 = 联合声明流产 + 元首拒绝合影 + 外交摩擦公开化。

**评分标准**：
- 8-10：外交互动活跃高效、经常推动实际成果、仪式成功率高
- 5-7：外交活跃但成果有限，或偶有外交失误
- 1-4：外交孤立、互动少、经常性或公开化的外交摩擦

---

### 维度三：盟友关系

**分析要点**：
- 盟友关系类型——条约军事同盟（硬捆绑）/ 战略伙伴（中等）/ 经济利益联盟（软关系）？
- 核心盟友 vs 边缘伙伴比例——真正的"无论如何都会支持"的国家有几个？
- 是否存在关系型互惠信号——盟友在不受利诱的情况下坚持支持？
- **国际联盟类型**：
  - **条约同盟**：北约、美日安保——最强绑定，类似"核心粉丝"
  - **战略伙伴**：全面/全天候战略合作伙伴——强连带
  - **经济利益联盟**：自贸区伙伴、一带一路参与国——利益驱动
  - **价值观联盟**：民主国家共同体、伊斯兰合作组织——身份驱动
  - **地缘平衡伙伴**：因共同威胁临时结盟——不稳定

**评分标准**：
- 8-10：盟友网络牢固、有条约级绑定、核心盟友数量充足
- 5-7：有稳定伙伴关系但多以经济/利益为主，缺乏硬绑定
- 1-4：盟友流失加速、孤立趋势明显、"老朋友"疏远

---

### 维度四：经济/贸易

**分析要点**：
- 经济驱动力——交易型（外交推动的单次贸易协议）还是关系型（盟友长期投资/FDI流入）？
- 经济韧性——GDP增长率稳定性、贸易依存度、外汇储备覆盖
- 是否存在过度依赖少数贸易伙伴的风险？（类似主播依赖榜一）
- **国家特有指标**：GDP增速、通胀率、经常账户差额、外汇储备、FDI流入趋势、贸易伙伴多元化指数

**评分标准**：
- 8-10：经济稳健增长、贸易结构多元、韧性高
- 5-7：经济尚可但波动大、或过度依赖单一产业/贸易伙伴
- 1-4：经济衰退、债务危机、恶性通胀、资本外逃

---

### 维度五：国内治理

**分析要点**：
- 是否有治理崩溃信号——腐败指数飙升、大规模抗议、政权非正常更迭、公共服务瘫痪？
- JD-R 的情绪失调对应：宣称的"人民至上" vs 实际治理指标（FSI/CPI/GINI）的矛盾？
- SDT 自主性信号——国家决策是否被外部势力严重约束（"被动治理"）？
- 社会支持缓冲——盟友/国际援助是否有效缓冲了内部危机？
- **国家特有指标**：Fragile States Index (FSI) 分数及趋势、透明国际腐败感知指数 (CPI)、基尼系数 (GINI) 不平等趋势、Freedom House 自由度评分、世界银行治理指标 (WGI)

**特别注意**：如果治理数据持续恶化但国家形象在国际上始终"稳定"（信息管控强/心之壁厚），标记为"⑥（国内治理→国家形象崩塌）因心之壁厚而沉默"——这是最高风险场景。典型案例：苏联解体前、委内瑞拉崩溃前。

**评分标准**：
- 8-10：治理健康、社会稳定、法治良好、公共服务高效
- 5-7：偶有治理波动信号但仍可控
- 1-4：明显治理危机、系统性腐败、公共服务崩溃、大规模社会动荡

---

### 维度六：软实力输出

**分析要点**：
- 软实力类型——文化（电影/音乐/文学/美食）、科技（创新/专利）、制度（治理模式输出）、价值观（意识形态吸引力）？
- 输出内容的国际接受度——是主动被接受还是依赖推广？
- 国家形象×软实力输出的匹配度——输出内容是否在品牌叙事同一性框架内（⑩ 国家形象→内容约束）？
- **国家特有指标**：Soft Power 30 / Global Soft Power Index 排名、电影出口票房、留学生流入数量、诺贝尔奖/奥运奖牌/文化产品出口

**评分标准**：
- 8-10：文化影响力强、创新引领全球、价值观有国际吸引力
- 5-7：有一定文化输出但影响力局限在区域、缺乏全球话语权
- 1-4：软实力疲弱、文化输出为零或负影响、国际话语权边缘化

## 五、心之壁判定标准

心之壁在国家层面是**系统性的**——制度性的信息管控体系，而非个人心理机制。它由技术层（互联网审查/防火墙）、制度层（新闻法/保密制度）、文化层（自我审查习惯）三层构成。

| 信号 | 解读 |
|------|------|
| 国家形象始终正面稳定 + 国内治理数据不可获取/不可信 + 从不公开承认治理问题 | **心之壁极厚**——消耗可能严重但表面看不出来（高风险假性稳定。典型案例：苏联解体前、委内瑞拉崩溃前） |
| 允许一定程度国际媒体准入 + 国际组织数据可获取 + 对治理问题有选择地承认 | **心之壁中等**——有门槛地开放后台信息 |
| 媒体自由 + 治理数据公开透明 + 国内矛盾被国际社会广泛报道和讨论 | **心之壁薄**——前台-后台高度渗透（通常对应成熟民主国家）。消耗可观测，但国际信任度通常更高 |
| 内部信息通过社交媒体/泄密突然大规模暴露 | **心之壁被外力打破**——Wikileaks/颜色革命/内部吹哨人 |
| 政权突然崩溃/革命/领导人突然下台 | **心之壁从内部崩溃**——积累的消耗一次性释放 |
| 国家媒体宣传正面 + FSI/CPI 等国际指数持续恶化 + 国际社会评估为"稳定" | **⚠ 最高风险：⑥因心之壁厚而沉默**——需明确标记 |

**⑥沉默风险检测方法**：
- FSI/CPI 数据不可获取 → 直接标记为"信息透明度不足，⑥无法检测"
- FSI/CPI/GINI 等指标持续恶化但国际形象评估稳定 → 标记为"⑥因心之壁厚而沉默，高风险假性稳定"
- FSI/CPI 数据透明度不足的国家 → 标记为"心之壁厚预警"

## 六、时间节奏驱动力映射

| 驱动力 | 主播对应 | 国家对应 |
|--------|---------|---------|
| Collins 互动仪式峰 | 弹幕刷屏、集体兴奋 | 重大外交突破（如中美建交、冷战结束）、历史性峰会成果 |
| ⑤ 外交表演消耗 | 情绪劳动消耗 | 维持国际承诺的经济/政治成本累积——如军备竞赛拖垮苏联 |
| ⑦ 认知负荷断点 | 话题空档 | 治理复杂度超过国家能力——如多民族国家的撕裂风险 |
| ⑥' 经济⇄治理螺旋 | 绩效反馈 | 增长飞轮（改革→增长→稳定）vs 衰退螺旋（衰退→不满→更衰退） |
| ERF 外生冲击 | 平台政策变化 | 全球疫情、地缘冲突、自然灾害、经济危机 |

> 如果信息显示"心之壁厚 + 国际评估长期'稳定'但内部指标持续恶化"，必须标注"⚠ 可能为厚壁假性平板，接近系统性崩溃"。

## 七、社群/体系维度分析指标（国际体系）

> 国家层面的"社群"即国际体系。国际体系存在独立于双边关系的群体动力学（如联盟内部压力、体系性极化）。

| 指标 | 分析问题 | 风险信号 |
|------|---------|---------|
| 联盟网络密度 | 有多少条约级盟友？经济/军事绑定比例？ | 密度过低→孤立；过高→过度牵连 |
| 盟友质量结构 | 核心盟友 vs 利益型伙伴的分布 | 全是利益型而无条约级→关系脆弱 |
| 国际体系位置 | 处于体系中心/半边缘/边缘？（世界体系理论） | 从中心向边缘滑落→⑥'衰退螺旋 |

## 十一、历史仪式记忆检索

（分析同一国家时，检索其历史分析报告以构建仪式链轨迹）

- **检索范围**：`analysis_reports/` 目录下该国的历史分析报告，以及 IMF Article IV Consultation 报告、World Bank Country Partnership Framework 等定期国际机构评估
- **对比维度**：同域仪式的连续成功/失败次数、外交孤立恢复周期变化、经济制裁恢复曲线、国家形象的域敏感性漂移
- **检索关键词**：`{国名} {事件类型} 历史 回顾` `/` `{国名} historical trend {指标}`
- **国家特有检索源**：
  - FSI（脆弱国家指数）逐年趋势对比（https://fragilestatesindex.org）
  - IMF Article IV 年度审议报告
  - World Bank CPIA（国家政策与制度评估）年度评分
  - WTO Trade Policy Review 定期审查
  - UN Human Development Report（HDI 趋势）
  - Soft Power 30 / Global Soft Power Index 年度排名变化
  - WGI（世界银行治理指标）六维度逐年数据
- **轨迹信号**：
  - 同域连续失败≥3（如连续三次在安理会投票中被多数反对） → 预期焦虑/外交资源预支
  - 经济制裁恢复周期逐次延长（第一次制裁2年恢复GDP增速、第二次3年、第三次5年+） → 经济韧性衰减效应
  - 国家形象域敏感性单向漂移（如从"新兴市场"向"不稳定国家"标签滑动、Brand Finance Nation Brands排名持续下降） → 国际叙事建构失败
  - 盟友网络密度逐年下降 + 外交活跃度反升 → "外交过度补偿"信号，对应⑤消耗加速
  - HDI止涨或下跌 + CPI连续恶化 + 外交互动频次不降 → ⑥心之壁厚沉默风险
