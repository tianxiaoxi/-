# 六道因果络 · 元技能参考

## 什么是"元技能"（Meta-Skill）

本 skill（`liudao-yinguo-luo`）是一个**元技能**——它不包含任何领域特定的分析逻辑，而是作为一个调度器，从领域注册表加载自包含的领域知识文件。所有领域知识均存放在 `domain_knowledge/` 目录下，不依赖任何外部 skill 文件。

### 核心设计原则

```
用户触发 "六道因果分析[目标]"
        │
        ▼
   Step 0-1: 识别目标领域
        │
        ▼
   Step 2: 加载领域知识
        │
   ┌────┴────────────────────────────┐
   │ 已有领域 (registry)            │ 新领域 (auto-generate)
   │ → 读取 domain_file 指向的      │ → Step 2b: 在线搜索+生成映射
   │   领域知识文件                  │ → 保存到 domain_knowledge/
   │ → 使用预设的维度/路径/模板     │
   └────┬────────────────────────────┘
        │
        ▼
   Step 3-8: 执行分析（搜索→评分→路径→交互面→节奏→社群）
        │
        ▼
   Step 9-10: 输出报告 → 保存
```

### 为什么是元技能

六道因果络框架的核心洞察是：**不同社会实体（主播/公司/国家）在结构上存在同构性**——它们都有前台呈现、后台状态、外部关系，以及前台-后台之间的边界机制。

这个同构性意味着可以用同一套因果路径网络去分析不同的实体类型，只需要替换每条路径的**语义映射**和**学科锚点**。

- 对主播：路径⑥是"个人状态→人设崩塌（Goffman 前台理论）"
- 对公司：路径⑥是"组织健康→品牌形象崩塌（企业印象管理）"
- 对国家：路径⑥是"国内治理→国家形象崩塌（State Failure Theory + FSI）"

框架结构不变，但每条路径的"说法"和"理论"随领域而变。元技能就是负责这个"随领域而变"的调度。

## 框架理论基础

六道因果络 v3 的完整理论见：

- **主文档**：`复盘提升词2/六道因果络_学科验证_v3.md` — 框架定位、双子系统架构、18条路径推导、学科锚定
- **国家版**：`复盘提升词2/六道因果络_国家版.md` — 国家领域的完整学科迁移映射

### 双子系统架构

v3 将框架划分为两个子系统 + 一个交互面：

| 组件 | 内容 | 核心理论 |
|------|------|---------|
| 子系统一：个人状态系统 | ⑤⑦⑦'⑨ 四条消耗路径 + ⑤'⑥' 缓冲反馈 | JD-R 理论 + COR 资源保存 |
| 子系统二：社交系统 | ①②③④②'⑩⑪⑫⑬ 互动-关系-产出网络 | Collins 互动仪式链 |
| 交互面 | 心之壁 + ⑧外部塑形 + ①↺'自我认知 + ERF | Snyder 自我监控 |

### 18条路径速查

| 编号 | 通用语义 | 理论锚点 |
|------|---------|---------|
| ① | 前台形象 ↔ 互动 | Goffman + Collins |
| ①↺' | 长期表演 → 自我认知偏移 | Bem 自我知觉 |
| ② | 互动 → 关系/粉丝 | Collins 互动仪式链 |
| ③ | 互动 ≈ 内容/产出 | Ong 口语文化 |
| ④ | 互动 → 资源(交易型) | 社会交换理论 |
| ⑤ | 互动 → 状态(情绪消耗) | JD-R Demands |
| ②' | 关系 → 资源(关系型) | 社会交换理论 |
| ⑤' | 关系 → 状态(缓冲) | Cohen & Wills 缓冲假说 |
| ⑥ | 状态 → 前台崩塌 | Goffman 后台泄露 |
| ⑥' | 资源 ↔ 状态(反馈) | Bandura 自我效能 |
| ⑦ | 内容/产出 → 状态(认知负荷) | JD-R + Sweller 认知负荷 |
| ⑦' | 运营行为 → 状态(基线消耗) | JD-R 生理消耗 |
| ⑧ | 关系 → 前台(外部塑形) | Snyder 自我监控 |
| ⑨ | 前台 → 状态(维护成本) | JD-R 角色维护 |
| ⑩ | 前台 → 内容(叙事约束) | Burgoon 期望违背 |
| ⑪ | 内容 → 关系(使用与满足) | Uses & Gratifications |
| ⑫ | 关系 → 内容(群体共创) | Jenkins 参与式文化 |
| ⑬ | 资源 → 内容(投入) | 资源投入回报 |
